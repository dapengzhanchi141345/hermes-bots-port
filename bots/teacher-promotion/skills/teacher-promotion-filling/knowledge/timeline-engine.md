# 时间逻辑引擎 - 核心计算规则与防Bug设计

## 一、时间计算三大核心概念（90%错误源）

### 1. 任职年限 ≠ 教龄 ≠ 工龄

| 概念 | 定义 | 申报核心 | 计算公式 |
|------|------|---------|---------|
| **任职年限** | 取得现职称并正式聘用起，至申报年度12月31日的连续年限 | ✅ 唯一核心年限 | 从聘书起始日→截止日 |
| **教龄** | 从一线教育教学工作开始计算的年限 | ❌ 不是申报核心 | 不同学段可相加 |
| **工龄** | 参加工作的总年限 | ❌ 基本无关 | 仅少数院校参考 |

**常见错误**：把教龄当任职年限填报，导致年限不足被打回。

### 2. 截止日规则

| 项目 | 截止日 | 说明 |
|------|--------|------|
| 任职年限计算截止 | 申报年度12月31日 | 安徽、山东、广东等统一口径 |
| 业绩材料截止 | 当年9月30日或通知指定日期 | 如山东2025年截止10月20日 |
| 继续教育学时截止 | 当年8月31日（广东）或通知日期 | 按当地要求 |
| 聘任年限截止 | 申报年度12月31日 | 以聘书为准 |

### 3. 起算日规则

| 来源 | 起算日 | 说明 |
|------|--------|------|
| 评审取得 | 评委会评审通过之日 | 非资格证取得日 |
| 考试取得 | 考试最后一天 | 如教师资格证考试 |
| 聘任取得 | 单位聘任文件起始日 | **不以资格证日期为准** |
| 转正定职 | 人社部门审批之日 | 大中专毕业生 |

## 二、任职年限精确计算

### 基础公式
```
任职年限 = floor((截止日 - 聘任起始日) / 365天)
          = 按周年计，满12个月为1年
          = 不足1年不计入有效年限
```

### 计算示例

**示例1**：2020年9月1日聘任二级教师，2025年申报一级教师
- 截止日：2024年12月31日
- 计算：2020.9.1 → 2024.12.31 = 4年4个月
- 任职年限：**4年** ✓ 符合本科申报一级教师4年要求

**示例2**：2020年11月1日聘任，2025年申报
- 截止日：2024年12月31日
- 计算：2020.11.1 → 2024.12.31 = 4年2个月
- 任职年限：**4年** ✓

**示例3**：2021年3月1日聘任，2025年申报
- 截止日：2024年12月31日
- 计算：2021.3.1 → 2024.12.31 = 3年10个月
- 任职年限：**3年** ✗ 不足4年，不符合要求

### 关键规则
1. **差1天也不满足**：严格按截止日核算
2. **以聘书为准**：不以资格证取得日计算
3. **按周年计**：不足12个月不计
4. **提前申报技巧**：2026年3月申报，年限算到2026年12月31日，不用等到年底

## 三、年度考核对年限的影响

### 影响规则
```
考核合格及以上：任职年限连续计算
考核基本合格：扣除当年度任职年限
考核不合格：扣除当年度任职年限 + 当年不得申报
```

### 计算示例
- 2020.9-2021.8：合格 → 计入1年
- 2021.9-2022.8：不合格 → 扣除0年
- 2022.9-2023.8：合格 → 计入1年
- 2023.9-2024.12：合格 → 计入1.25年（取整不计入，算0）
- 有效年限：**2年**（仅2020-2022两年合格）

## 四、班主任年限计算规则

### 基础要求

| 申报级别 | 累计班主任年限要求 | 任现职以来要求 |
|---------|------------------|---------------|
| 高级教师 | ≥5年 | ≥2年 |
| 一级教师 | ≥3年 | ≥2年 |
| 正高级教师 | ≥10年 | 按当年政策 |

### 可视作班主任年限的特殊情况

| 情况 | 折算规则 | 是否计入量化 |
|------|---------|-------------|
| 学校中层及以上管理 | 满1年计1年 | 视同，不计量化分 |
| 少先队大队辅导员 | 满1年计1年 | 视同，不计量化分 |
| 中学团委书记 | 满1年计1年 | 视同，不计量化分 |
| 德育导师 | 满1年计1年 | 视同，不计量化分 |
| 心理健康教育专职教师 | 满1年计1年 | 视同，不计量化分 |
| 音体美信等社团辅导 | 满2年计1年（班主任年限） | 视同，不计量化分 |
| 资源教师 | 满1年计1年 | 视同，不计量化分 |
| 小学副班主任 | 满2年计1年（班主任年限） | 视同，不计量化分 |

### 禁止重复计算
班主任年限与视同班主任年限**不得重复计算**。

### 特殊豁免
以下人员**不作班主任年限要求**：
- 信息技术/通用技术/音乐/体育/美术/科学/综合实践学科教师（无拒绝证明）
- 教研员、电教教师
- 具有博士学位申报高级教师者（需从教2年以上，任现职1年以上）
- 特殊教育教师（从教以来4年以上）

## 五、材料有效时段计算

### 广东规则（2021年后取得职称）
```
有效材料起算 = 本级职称评审年度次年1月1日
有效材料截止 = 申报高一级职称评审年度12月31日
```

**示例**：2022年取得一级教师，2026年申报高级教师
- 有效材料起算：2023年1月1日
- 有效材料截止：2026年12月31日

### 广东规则（2020年及以前取得职称）
```
有效材料起算 = 本级职称评审年度9月1日
有效材料截止 = 申报高一级职称评审年度12月31日
```

**示例**：2019年取得一级教师，2026年申报高级教师
- 有效材料起算：2019年9月1日
- 有效材料截止：2026年12月31日

## 六、课时量计算规则

### 工作量标准
- 以本校平均工作量计算
- 学校出具工作量证明为依据
- 行政领导课时量不低于专任教师的1/3
- 中层干部课时量不低于专任教师的1/2

### 特殊计算
- 实习(周)：按16学时折算
- 实验上机：按1.5倍折算
- 线上课时：按实际折算

## 七、特殊情形年限折算

### 扣除情形
| 情形 | 处理 |
|------|------|
| 全脱产学习>1年 | 扣除相应年限 |
| 一学期以上长期病假 | 扣除相应时间 |
| 离职后重新入职 | 离职期间年限扣除，重新计算 |
| 借调期间未履职 | 不计算在履职时间内 |
| 未在教学岗位工作 | 不计算在履职年限内 |

### 不扣除情形
| 情形 | 处理 |
|------|------|
| 产假 | 不扣除，连续计算 |
| 病假(凭医院证明) | 不扣除，连续计算 |
| 哺乳假 | 不扣除，连续计算 |

### 折算情形
| 情形 | 处理 |
|------|------|
| 国内访学>6个月 | 部分高校允许折算任职年限 |
| 挂职锻炼>6个月 | 可缩短任职年限1年申报 |
| 援疆/援藏/援青 | 可提前1年申报（3年期满） |
| 革命老区/中央苏区工作>4年 | 申报中高级职称可缩短1年 |

### 转系列规则
```
转系列评审条件：
1. 在现岗位工作满1年方可申报转系列
2. 同系列相近岗位：原工作年限/任职年限可累计
3. 跨系列转评：需重新聘任满1年，再累计原年限
4. 同一年度不得同时转评和晋升
```

## 九、时间逻辑Bug检测清单

### P0致命错误（直接驳回）
- [ ] 任职年限不足要求年限
- [ ] 年度考核不合格年份未扣除
- [ ] 材料时间超出有效时段
- [ ] 班主任年限计算重复
- [ ] 聘任起始日以资格证日期代替

### P1严重错误（初审打回）
- [ ] 工作经历时间断档未说明
- [ ] 借调/支教期间未扣除履职时间
- [ ] 全脱产学习期间未扣除
- [ ] 转系列未满足1年过渡期
- [ ] 课时量证明与实际情况不符

### P2格式错误（要求修改）
- [ ] 日期格式不统一（YYYY.MM vs YYYY年MM月）
- [ ] 位次填写格式错误（"第1名" vs "1/3"）
- [ ] 学段学科填写不规范（"初中" vs "初中物理"）
- [ ] 外语教师填写"高中外语"而非具体语种

## 十、自动化计算函数（伪代码）

```python
def calc_tenure_years(hire_date, cutoff_date, assessment_records):
    """计算有效任职年限"""
    total_months = months_between(hire_date, cutoff_date)
    years = total_months // 12
    # 扣除不合格年份
    for record in assessment_records:
        if record['year'] <= years:
            years -= 1
    return years

def calc_homeroom_years(works, conversion_rules):
    """计算班主任年限（含折算）"""
    total_years = 0
    for work in works:
        if work['role'] == 'homeroom':
            total_years += months_between(work['start'], work['end']) / 12
        elif work['role'] == 'vice_homeroom':
            # 副班主任2年折1年
            total_years += months_between(work['start'], work['end']) / 24
        elif work['role'] in conversion_rules:
            # 特殊岗位折算
            factor = conversion_rules[work['role']]
            total_years += months_between(work['start'], work['end']) * factor
    return total_years

def check_material_validity(material_date, eval_year, is_2021_plus=True):
    """检查材料是否在有效时段内"""
    if is_2021_plus:
        start = f"{eval_year + 1}-01-01"
    else:
        start = f"{eval_year}-09-01"
    end = f"{eval_year + 1}-12-31"
    return start <= material_date <= end

def check_tenure_sufficient(calc_years, required_years):
    """检查任职年限是否达标"""
    return calc_years >= required_years
```

## 十二、申报年份预判工具

```
用户输入：
- 聘任日期：2020.9
- 当前学历：本科
- 目标级别：高级教师
- 年度考核：2021合格，2022不合格，2023合格，2024合格

计算过程：
1. 一级→高级需5年任职年限
2. 聘任起始：2020.9
3. 2025年12月31日截止：5年4个月→5年 ✓
4. 扣除2022不合格年份：5-1=4年 ✗
5. 结论：2025年申报不合格，需等到2026年

建议：2026年申报，年限5年（2020.9-2025.12），扣除1年不合格=4年
      仍不足5年，建议2027年申报
```
