## 二、自动检测规则库（25项）

### R01 - 任职年限计算错误
**检测规则**：
```
IF 聘任起始日 IS NULL:
    → 错误：无法计算任职年限
    → 修复：要求用户提供聘书起始日
    
IF 聘任起始日 > 申报年度12月31日:
    → 错误：聘任日期在未来
    → 修复：检查日期格式或重新录入
    
IF 任职年限 < 学历要求年限:
    → 错误：年限不足，无法申报
    → 修复：计算最早可申报年份
```

**计算公式**：
```
任职年限 = floor((申报年度12月31日 - 聘任起始日) / 365)
考核不合格年份扣除 = count(不合格年度考核)
有效任职年限 = 任职年限 - 考核不合格年份扣除
```

### R02 - 班主任年限计算错误
**检测规则**：
```
IF 班主任年限从"从教以来"计算:
    → 错误：应从任现职以来计算
    → 修复：重新计算任现职以来的班主任年限
    
IF 班主任年限 + 视同班主任年限 > 总年限:
    → 错误：重复计算
    → 修复：明确区分班主任与视同班主任
    
IF 副班主任年限未×0.5折算:
    → 错误：副班主任应按2年折1年计算
    → 修复：自动折算
```

**班主任折算规则**：
| 角色 | 折算系数 | 备注 |
|------|---------|------|
| 班主任 | 1.0 | 满1年计1年 |
| 副班主任 | 0.5 | 满2年计1年 |
| 学校中层及以上管理 | 1.0 | 视同，不计量化 |
| 少先队大队辅导员 | 1.0 | 视同，不计量化 |
| 中学团委书记 | 1.0 | 视同，不计量化 |
| 德育导师 | 1.0 | 视同，不计量化 |
| 音体美信社团辅导 | 0.5 | 满2年计1年，视同 |
| 心理健康教育专职教师 | 1.0 | 视同，不计量化 |
| 资源教师 | 1.0 | 视同，不计量化 |
| 小学副班主任 | 0.5 | 满2年计1年 |

### R03 - 材料有效时段错误
**检测规则**：
```
IF 取得职称年份 >= 2021:
    有效时段起算 = 本级职称评审年度次年1月1日
ELSE:
    有效时段起算 = 本级职称评审年度9月1日
    
IF 材料日期 < 有效时段起算 OR 材料日期 > 申报年度12月31日:
    → 错误：材料超出有效时段
    → 修复：标注"无效材料"，建议替换
```

### R04 - 工作经历断档检测
**检测规则**：
```
FOR 每段工作经历[i]:
    IF 工作经历[i].end_date != 工作经历[i+1].start_date:
        → 错误：工作经历时间断档
        → 修复：要求补充证明或说明原因
        
IF 断档原因不在[脱产学习, 借调, 病假, 产假, 挂职]:
    → 严重错误：断档无合理解释
    → 修复：要求提供相关部门证明
```

### R05 - 继续教育学时检测
**检测规则**：
```
IF 申报级别 == 高级:
    需继续教育年限 = 5年
ELSE IF 申报级别 == 中级:
    需继续教育年限 = 4年
ELSE:
    需继续教育年限 = 1年
    
FOR 每一年 in 需继续教育年限:
    IF 该年总学时 < 90:
        → 错误：该年度学时不达标
        → 修复：提供补修方案（线上平台/成果折抵）
        
    IF 公需课学时 < 30:
        → 错误：公需课学时不足
        → 修复：优先补修公需课（有截止时间）
        
    IF 专业课题时 < 60:
        → 错误：专业课题时不足
        → 修复：选择与申报专业匹配的课程
```

### R06 - 公开课与申报专业一致性检测
**检测规则**：
```
IF 公开课.学科 != 申报学科:
    → 错误：公开课与申报专业不一致
    → 修复：要求提供与申报专业一致的公开课
    
IF 公开课数量 < 申报要求最低数量:
    → 错误：公开课数量不足
    → 修复：补充符合要求的公开课
```

### R07 - 循环教学检测
**检测规则**：
```
IF 循环教学时长 != 毕业班任教时长:
    → 错误：循环教学与毕业班任教数据不一致
    → 修复：以证明为准，系统填写需一致
    
IF 循环教学重复计算:
    → 错误：同一时间段在循环教学和毕业班任教中重复计算
    → 修复：按年度分开填写，不重复计算
```

### R08 - 课时量一致性检测
**检测规则**：
```
IF 工作量证明.年均课时 != 系统填写.年均课时:
    → 错误：证明与系统课时量不一致
    → 修复：以年度为单位分别填写，确保一致
    
IF 年均课时 < 学校平均课时量的1/3(行政领导) OR 1/2(中层干部):
    → 错误：课时量不达标
    → 修复：补充工作量证明或调整填写
```

### R09 - 论文期刊合法性检测
**检测规则**：
```
IF 论文.journal NOT IN 合法期刊列表:
    → 错误：期刊可能非正规
    → 修复：要求提供CN/ISSN号，核实期刊合法性
    
IF 论文.journal IN [增刊, 特刊, 专刊, 电子刊]:
    → 致命错误：非正规期刊，一票否决
    → 修复：更换正规期刊发表的论文
    
IF 论文.author_position != "第一作者" AND 论文.author_position != "通讯作者":
    → 警告：非第一作者，可能不计入核心成果
    → 修复：确认是否符合评审要求
```

### R10 - 课题状态检测
**检测规则**：
```
IF 课题.status == "在研":
    → 错误：课题未结题，无法作为业绩成果
    → 修复：要求提供结题证书或更换已结题课题
    
IF 课题.date < 有效时段起算:
    → 错误：课题立项时间超出有效时段
    → 修复：标注无效，建议补充有效时段内的课题
```

### R11 - 学历完整性检测
**检测规则**：
```
IF 学历数量 < 实际学历数量:
    → 错误：学历填写不完整
    → 修复：补充所有学历（从第一学历到最高学历）
    
IF 学历.专业 != 申报学科 AND 学历.专业 NOT IN [相近专业列表]:
    → 警告：专业不一致
    → 修复：确认是否符合转评要求
```

### R12 - 姓名一致性检测
**检测规则**：
```
IF 身份证.name != 档案.name:
    → 错误：姓名不一致
    → 修复：要求提供公安机关证明或档案盖章证明
    
IF 身份证.name != 教师资格证.name:
    → 错误：姓名不一致
    → 修复：核对证件信息，必要时提供变更证明
    
IF 职称证书.name != 身份证.name:
    → 错误：姓名不一致
    → 修复：核对所有证件姓名
```

### R13 - 奖项时效性检测
**检测规则**：
```
IF 获奖.日期 < 任现职以来起始日:
    → 错误：获奖在任现职以前，不计入业绩
    → 修复：标注"无效业绩"，建议替换
    
IF 获奖.批准机关 NOT IN 有效批准机关列表:
    → 错误：证书未经备案或批准机关无效
    → 修复：更换经省级以上部门批准的奖项
```

### R14 - 支教经历检测
**检测规则**：
```
IF 支教.每周课时 < 最低要求课时:
    → 错误：支教工作量不足
    → 修复：要求提供完整工作量证明
    
IF 支教.证明日期与系统填写日期不一致:
    → 错误：支教经历时间不一致
    → 修复：确保证明与系统填写完全一致
```

### R15 - 示范引领公开课排序检测
**检测规则**：
```
IF 公开课列表 NOT SORTED BY date DESC:
    → 错误：公开课时间排序混乱
    → 修复：按从近到远排序
```

### R16 - 培养青年教师检测
**检测规则**：
```
IF 培养青年教师数量 < 申报要求最低数量:
    → 错误：培养青年教师数量不足
    → 修复：补充培养证明或调整预期
    
IF 培养时间段 NOT IN 近五年:
    → 错误：培养青年教师时间超出有效时段
    → 修复：更换近五年内的培养经历
```

### R17 - 校本教研检测
**检测规则**：
```
IF 校本教研.立项时间 > 评审表.批准时间:
    → 错误：时间逻辑冲突（立项在后，批准在前）
    → 修复：检查并修正时间填写
    
IF 教研活动次数 < 文件要求:
    → 错误：教研活动不足
    → 修复：补充近五年教研活动记录（主持完成）
```

### R18 - 循环教学与毕业班任教一致性检测
**检测规则**：
```
IF 循环教学证明.毕业班时长 != 系统填写.毕业班时长:
    → 致命错误：证明与系统完全不符
    → 修复：以证明为准，重新填写系统
```

### R19 - 正高教师试讲答辩要求检测
**检测规则**：
```
IF 申报级别 == 正高级:
    IF 试讲视频格式 NOT IN [mp4, flv]:
        → 错误：视频格式不符合要求
        → 修复：转换为mp4或flv格式

    IF 未体现专家镜头:
        → 错误：录像不规范
        → 修复：重新录制，体现推荐专家镜头
        
    IF 文件命名 NOT MATCH "区县+单位+姓名":
        → 错误：文件命名不规范
        → 修复：按规范重新命名
```

### R20 - 六公开监督卡上传检测

IF 申报级别 == 正高级:

### R22 - 课时量公示备案检测
**检测规则**：
```
IF 课时量未完成校内公示:

    → 修复：每学期结束后校内公示≥5个工作日
    
IF 课时量未在系统中备案:
    → 错误：未在教师管理信息系统备案
    → 修复：在全国教师管理信息系统备案

### R23 - 基层职称换发条件检测
**检测规则**：
```

        → 错误：基层聘任不满5年

        → 修复：选择一种类型申报

### R24 - 改系列申报检测
**检测规则**：
```

        → 错误：改系列需满1年过渡期
        → 修复：在现岗位工作满1年后再申报
        
    IF 当年度申报高一级职称:
        → 错误：改系列当年度不得申报高一级
        → 修复：改系列与晋升分开申报
```

### R25 - 教学能力测评等次检测
**检测规则**：
```
IF 申报级别 == 正高级 OR 申报级别 == 高级:
    IF 教学能力测评未参加:
        → 警告：建议参加教学能力测评
        → 说明：测评结果分为A/B/C/D四等次，影响评审
        
    IF 测评等次为D:
        → 严重：测评等次不达标
        → 修复：提升教学能力，争取A/B/C等次
```

## 三、自动修复引擎

### 修复优先级
```
P0致命错误 → 立即阻断，必须修正
P1严重错误 → 强烈建议修正，否则初审打回
P2警告提示 → 可选修正，影响评审印象
```

### 自动修复规则

| 错误类型 | 自动修复操作 | 人工确认 |
|---------|-------------|---------|
| 日期格式不统一 | 统一为YYYY.MM格式 | 否 |
| 位次格式错误 | "第1名"→"1/1"，"第2位"→"2/3" | 是 |
| 学段学科不规范 | "初中"→"初中物理" | 是 |
| 继续教育学时不足 | 计算缺口，推荐补修方案 | 否 |
| 材料排序混乱 | 按时间倒序自动排序 | 否 |
| 字段重复填写 | 删除重复条目，保留最新 | 是 |
| 学历不完整 | 提示补充第一学历 | 否 |
| 公开课排序混乱 | 自动按时间倒序排序 | 否 |

### 修复示例

**示例1：任职年限计算自动修复**
```
输入：
- 聘任日期：2020年9月1日
- 申报级别：高级教师
- 学历：本科
- 年度考核：2021合格，2022合格，2023不合格，2024合格

计算过程：
1. 一级→高级需5年任职年限
2. 聘任起始：2020.9.1
3. 2025年申报，截止日：2024.12.31
4. 计算：2020.9.1 → 2024.12.31 = 4年4个月 → 4年
5. 扣除2023不合格年份：4-1=3年
6. 结论：3年 < 5年，2025年不合格

自动修复建议：
- 2025年申报：❌ 不合格（任职年限3年，需5年）
- 2026年申报：❌ 不合格（任职年限4年，需5年）
- 2027年申报：❌ 不合格（任职年限5年，扣除1年不合格=4年，需5年）
- 2028年申报：✓ 合格（任职年限6年，扣除1年不合格=5年）
- 建议申报年份：2028年
```

**示例2：班主任年限自动修复**
```
输入：
- 班主任：2020.9-2023.7（3年）
- 副班主任：2018.9-2020.8（2年）
- 少先队大队辅导员：2021.9-2024.8（3年）
- 时间断档：2023.7-2024.8（副班主任与辅导员时间重叠）

自动修复：
1. 班主任：3年（2020.9-2023.7）
2. 副班主任折算：2年×0.5=1年（2018.9-2020.8）
3. 少先队辅导员（视同）：3年（2021.9-2024.8）
4. 但2021.9-2023.7与班主任重叠，需扣除
5. 有效班主任年限：3 + 1 = 4年
6. 有效视同班主任年限：3 - 2 = 1年（2023.9-2024.8）
7. 总年限：4 + 1 = 5年 ✓（申报高级教师需≥5年）
```
