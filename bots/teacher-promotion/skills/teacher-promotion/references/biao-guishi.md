### 时间逻辑核心规则（新增）

#### 三大核心概念
1. **任职年限**：取得现职称并正式聘用起，至申报年度12月31日的连续年限（唯一核心）
2. **教龄**：从一线教育教学工作开始计算的年限（不是申报核心）
3. **工龄**：参加工作的总年限（基本无关）

**常见错误**：把教龄当任职年限填报，导致年限不足被打回。

#### 截止日规则
| 项目 | 截止日 | 说明 |
|------|--------|------|
| 任职年限计算截止 | 申报年度12月31日 | 统一口径 |
| 业绩材料截止 | 当年9月30日或通知日期 | 如山东截止10月20日 |
| 继续教育截止 | 当年8月31日（广东）等 | 按当地要求 |
| 聘任年限截止 | 申报年度12月31日 | 以聘书为准 |

#### 起算日规则
| 来源 | 起算日 | 说明 |
|------|--------|------|
| 评审取得 | 评委会评审通过之日 | 非资格证取得日 |
| 考试取得 | 考试最后一天 | 如教师资格证考试 |
| 聘任取得 | 单位聘任文件起始日 | **不以资格证日期为准** |

#### 任职年限计算公式
```
任职年限 = floor((截止日 - 聘任起始日) / 365天)
          = 按周年计，满12个月为1年
          = 不足1年不计入有效年限
```

**示例**：2020年9月1日聘任二级教师，2025年申报一级教师
- 截止日：2024年12月31日
- 计算：2020.9.1 → 2024.12.31 = 4年4个月
- 任职年限：**4年** ✓ 符合本科申报一级教师4年要求

#### 年度考核对年限的影响
| 考核结果 | 处理 |
|---------|------|
| 合格及以上 | 任职年限连续计算 |
| 基本合格 | 扣除当年度任职年限 |
| 不合格 | 扣除当年度任职年限 + 当年不得申报 |

### 申报年份预判工具
```
用户输入：聘任日期 + 当前学历 + 目标级别 + 年度考核记录
计算：有效任职年限 = floor((申报年度12月31日 - 聘任起始日) / 365) - 不合格年份数
判断：是否满足申报要求
输出：建议申报年份 + 具体等待时间
```

### 常见时间逻辑Bug
1. **把教龄当任职年限**：90%错误源
2. **以资格证日期代替聘书日期**：应以聘书起始日为准
3. **考核不合格年份未扣除**：需逐条核对年度考核表
4. **班主任与视同班主任重复计算**：禁止重复
5. **材料时间超出有效时段**：按2020前/后两档规则校验
6. **差1天不满年限**：严格按截止日核算，无余地

## 工作流程

1. 接收用户提供的省份+学段+级别
2. 确认评审标准和时间逻辑要求
3. 执行时间逻辑计算（任职年限、班主任年限、材料时效）
4. 对照申报条件判断是否达标
5. 输出标准查询结果 + 时间逻辑校验报告

## 输出规范

- 评审标准以表格形式呈现
- 材料清单标注"必备/限项/特殊"
- 填表规范逐条说明
- 时间逻辑计算展示公式和过程
- 常见错误标注"错误→正确"对照
- 达标判定明确给出"符合/不符合"

## 注意事项

- 评审标准会随年度更新，需确认最新政策
- 各省市可能有地方性补充要求
- 特殊情况（转评、破格、乡村绿色通道）需单独说明
- 时间逻辑计算以用户提供的数据为准，必要时提醒用户向人事处确认官方年限认定

### 升级后的工作流

1. **锁条件**：拉取该省该年度该级别的完整条件清单。
2. **分类**：必备 / 择优 / 破格三类。
3. **时间轴**：建立任职、班主任、支教等时间轴并校验。
4. **逐条比对**：每项条件给「符合 / 不符合 / 待确认」。
5. **输出**：条件对照表 + 缺口清单 + 补齐建议。

## 协作机制（结构补强 · 2026-09 第二轮）

### 上下文快照传递格式（跨阶段必用）
每个阶段收尾、下一位成员开工前，主理人传递：

> 【阶段快照 N】
> - 输入摘要：{本阶段收到的关键信息，≤3 行}
> - 已产出：{本阶段成果清单 + 置信度}
> - 遗留问题：{未决点/需下游确认项}
> - 交接指令：{下游应做什么}

规则：禁止只传一句话，也禁止把上游全文无筛选倒灌；快照必须包含「遗留问题」，下游不得静默丢弃。

### 成员启动失败降级链（统一预案）
专职成员 → 全能替补（以成员身份工作） → 通用 agent + 交叉训练技能 → 主理人自兜底（必须标注「替补模式，产出降一级置信度」）
触发条件：成员 2 次 spawn 失败或 5 分钟无回传即切换；切换后向用户通报一句「已启用备用方案」，不静默。

### 质量门禁执行（对齐全员「前沿技术栈」章节）
- 门禁项必须可勾选、可追溯：交付物中逐项打 ✅/❌，❌ 项给修复路径
- 涉评分结论：AI 初评必须标「待人工复核」；抽样双评计算一致性（QWK/Krippendorff α），低于 0.7 停用自动给分
- 涉前沿论断：逐条附可核查来源（名称+年份，优先 DOI），无来源不输出
- 涉政策/考试：标注「以当地最新官方文件为准」
- 涉命理：标注「仅供文化参考，不作医疗/投资决策依据」
- 涉交易：标注风险提示，不承诺收益
