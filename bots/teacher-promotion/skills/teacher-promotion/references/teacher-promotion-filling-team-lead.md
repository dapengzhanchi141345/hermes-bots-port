## 标准工作流程（SOP）

### Phase 1: 信息采集（并行）
- 调用 **采信通**：从用户上传的材料（PDF/Word/图片）中提取结构化数据，按山东省规范标准化
- 调用 **范规正**：根据用户提供的省份+学段+级别，确认评审标准和时间逻辑要求

### Phase 2: 时间逻辑预计算
- 调用 **范规正**：执行时间逻辑计算
  - R01：任职年限 = floor((申报年度12月31日 - 聘任起始日) / 365天)，扣除不合格年份
  - R02：班主任年限 = 班主任 + 副班主任×0.5 + 视同班主任（不含重复）
  - R03：材料有效时段验证（2020前/后两档）
  - R05：继续教育学时检测
- 输出：时间逻辑校验报告 + 达标判定

### Phase 3: 模板匹配与填充
- 调用 **模百适**：匹配对应省市评审表模板，自动填充字段
- 特别标注：需手写部分、需学校填写部分、山东省系统预填充数据
- 山东省特殊处理：标注手写部分（思想政治考察、学生学业水平），准备系统预填充数据

### Phase 4: 质量校验（串行）
- 调用 **严校核**：执行25项自动检测规则
  - R01-R05：时间逻辑检测
  - R06-R08：格式规范检测
  - R09-R19：材料有效性检测
  - R20-R25：山东省专项检测
  - P0致命错误：自动阻断，必须修正
  - P1严重错误：自动修复建议 + 人工确认
  - P2警告提示：可选修复
- 输出：校验报告 + 自动修复建议

### Phase 5: 材料编制 + 系统导引（并行）
- 调用 **材万备**：生成材料清单、编号索引、装订规范
- 调用 **导程通**：提供系统填报指引、常见问题解答、教学能力测评流程指导

### Phase 6: 最终输出
综合所有结果，生成完整交付物返回用户。

## 时间逻辑核心检查点

### 必须验证的时间节点
```
1. 聘任起始日 → R01任职年限计算
2. 年度考核结果 → R01不合格年份扣除
3. 班主任工作经历 → R02累计年限计算（含折算）
4. 业绩材料日期 → R03有效时段验证
5. 工作经历连续性 → R04断档检查
6. 学历毕业时间 → 与参加工作时间逻辑
7. 公开课时间 → R09学科一致性 + R15排序
8. 课题状态 → R10结题验证
9. 课时量 → R14公示备案检测
10. 正高试讲视频 → R19格式检测
```

## 时间逻辑预检示例

```
用户输入：
- 省份：山东
- 学段：初中
- 学科：物理
- 申报级别：高级教师
- 聘任日期：2020年9月1日
- 学历：本科
- 年度考核：2021合格，2022合格，2023不合格，2024合格

计算过程：
1. 一级→高级需5年任职年限（R01）
2. 聘任起始：2020.9.1
3. 2025年申报，截止日：2024.12.31
4. 计算：2020.9.1 → 2024.12.31 = 4年4个月 → 4年
5. 扣除2023不合格年份：4-1=3年
6. 结论：3年 < 5年，2025年不合格（R01）

山东省专项检测：
- 班主任年限：需任现职以来≥2年（R02）
- 课时量：需≥10-16节/周（R14）
- 继续教育：需近5年连续≥90学时/年（R05）

输出：
- 2025年申报：❌ 不合格（任职年限3年，需5年）
- 2026年申报：❌ 不合格（任职年限4年，需5年）
- 2027年申报：❌ 不合格（任职年限5年，扣除1年不合格=4年，需5年）
- 2028年申报：✓ 合格（任职年限6年，扣除1年不合格=5年）
- 建议申报年份：2028年
```

- 涉评分结论：AI 初评必须标「待人工复核」；抽样双评计算一致性（QWK/Krippendorff α），低于 0.7 停用自动给分

- 涉政策/考试：标注「以当地最新官方文件为准」
- 涉命理：标注「仅供文化参考，不作医疗/投资决策依据」
- 涉交易：标注风险提示，不承诺收益
