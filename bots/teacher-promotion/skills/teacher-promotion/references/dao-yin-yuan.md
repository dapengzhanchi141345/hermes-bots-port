## 山东省系统填报字段详解

### "基本信息"栏目

| 字段 | 填写说明 | 上传材料 |
|------|---------|---------|
| 姓名 | 与身份证一致 | 身份证正反面 |

### "申报信息"栏目

| 字段 | 填写说明 | 常见错误 |
|------|---------|---------|
| 申报级别 | 正高级/副高级/中级/初级 | 选错级别 |
| 申报系列 | 中小学教师 | 填错系列 |
| 申报方式 | 正常晋升/改系列评审/高层次人才直通车 | 改系列选错 |

| 是否委托评审 | 全部选择"否" | 选错 |

## 山东省教学能力测评流程

### 测评等次
- A（优秀）、B、C、D四个等次
- A、B、C等次各不超过推荐总数的25%

### 测评方式
| 申报级别 | 组织单位 | 测评方式 |
|---------|---------|---------|
| 正高级 | 市教育局统一组织 | 试讲15分钟 + 答辩5分钟 |
| 高级（市直） | 市教育局统一组织 | 试讲15分钟 + 答辩5分钟 |
| 高级（区县） | 区县教育行政部门组织 | 讲课答辩、教学业绩考察 |
| 中级 | 各学校自行制定方案 | 讲课答辩等 |

### 正高/高级试讲要求
```
1. 聘请异地副高级以上专家
2. 试讲时间：15分钟
3. 答辩时间：5分钟
4. 试讲内容：从申报教师2024-2025学年第二学期任教课程中选取
5. 全程录像，体现推荐专家镜头，画面清晰
6. 视频格式：mp4/flv，≤300M
7. 文件命名：区市+单位+姓名
```

### 测评材料报送
- 正高级：评审表原件3份 + 报刊著作原件1份 + 试讲视频 + 纸质材料2份
- 高级：评审表原件1份 + 试讲视频
- 视频需刻盘或拷贝优盘报送

## 常见问题处理

| 问题 | 解决方案 |
|------|---------|
| 系统打不开 | 检查网络、更换浏览器（推荐Chrome） |
| 照片上传失败 | 检查格式（jpg/png）、大小（<2MB）、白底或浅蓝底 |
| PDF合并失败 | 使用在线工具（ilovepdf、迅捷PDF） |
| 字段无法填写 | 检查是否选择正确申报级别 |
| 附件上传超限 | 压缩PDF或分批次上传 |
| 班主任年限计算 | 含副班主任，不同学段可相加 |
| 外语教师学科填写 | 填具体语种如"高中日语"，不填"高中外语" |
| 位次填写格式 | 个人独立填"1/1"，合作填"位次/总人数"如"1/3" |
| 档案出生日期不一致 | 上传《三龄一历认定表》或《干部人事档案专项审核认定表》 |
| 改系列申报 | 选择"改系列评审"，需满1年过渡期 |
| 课时量备案 | 每学期结束后校内公示≥5个工作日，在全国教师管理信息系统备案 |

## 协作机制（结构补强 · 2026-09 第二轮）

### 上下文快照传递格式（跨阶段必用）
每个阶段收尾、下一位成员开工前，主理人传递：

> 【阶段快照 N】
> - 输入摘要：{本阶段收到的关键信息，≤3 行}
> - 已产出：{本阶段成果清单 + 置信度}
> - 遗留问题：{未决点/需下游确认项}
> - 交接指令：{下游应做什么}

规则：禁止只传一句话，也禁止把上游全文无筛选倒灌；快照必须包含「遗留问题」，下游不得静默丢弃。

### 成员启动失败降级链（统一预案）
专职成员 → 全能替补（以成员身份工作） → 通用 agent + 交叉训练技能 → 主理人自兜底（必须标注「替补模式，产出降一级置信度」）
触发条件：成员 2 次 spawn 失败或 5 分钟无回传即切换；切换后向用户通报一句「已启用备用方案」，不静默。

### 质量门禁执行（对齐全员「前沿技术栈」章节）
- 门禁项必须可勾选、可追溯：交付物中逐项打 ✅/❌，❌ 项给修复路径
- 涉评分结论：AI 初评必须标「待人工复核」；抽样双评计算一致性（QWK/Krippendorff α），低于 0.7 停用自动给分
- 涉前沿论断：逐条附可核查来源（名称+年份，优先 DOI），无来源不输出
- 涉政策/考试：标注「以当地最新官方文件为准」
- 涉命理：标注「仅供文化参考，不作医疗/投资决策依据」
- 涉交易：标注风险提示，不承诺收益
