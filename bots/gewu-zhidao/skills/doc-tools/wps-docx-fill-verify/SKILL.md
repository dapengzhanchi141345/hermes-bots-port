# 官方 Word 模板填写与版式核验（WPS 工具链）

本类任务＝把文本灌进官方 .doc 模板（申请书/活页/汇总表），**版式 100% 保留**，且必须亲眼核验填对没填错框。用户偏好：常纠偏「你填错框了」「版式不能变」「你先学会看表格再处理」「把填表说明研讨透了」。结论先行，不要复述过程。

## 前置：读官方「填写说明」逐字，不凭记忆
- 模板通常自带「填写数据表注意事项」N 条 + 提纲。逐条抠出：选项填字母码还是自由文本、限报几项、经费单位、代码格式（类别码+三位编号）、活页匿名红线、字数上限。
- 选项填写格式务必对齐官方**示例**（如「B ∣ 教育心理」「Z ∣ 重点课题」），再对应到模板实际物理框。填表说明的示例是标准答案，模板框结构要 dump 确认。
- **官方附件成套要全部学完再动手**（用户明令「附件1–6 学完就知道了」「严格按模板的格式/版式/字体要求来」）：选题指南（附件1）查选题分类/限报项；管理办法（附件6）查申报/匿名/字数硬规；申请·评审书（附件3）与匿名活页（附件4）模板本身 = 版式字体基准。官方规定常**不在文字说明里而藏在模板 XML 的 run 属性**，文字 grep 无果时用下方「官方版式/字体基准 dump 法」逐段逐格 dump。
- 同一课题目录里若存在多份「_已填/_美化/_new」等历史版本，**以官方模板原件（附件N .doc）转出的 docx 为唯一基准**：历史简版可能表结构不完整（丢表格/丢「——活页N——」标记），直接在其上升级=版式事故。开工前先比对历史版的表格数/段落数与官方模板是否一致，不一致就基于官方模板重填而非修补旧版。

## 第1步：.doc → .docx（保留版式）
- 本机无 LibreOffice/soffice。用 WPS COM headless 转：
  - doc 用 `Kwps.Application`，`SaveAs(dst, 12)`（12=Word 格式码；16 会转出 OLE 旧格式不是真 docx）。
  - ppt 用 `KWPP.Application`，`Presentations.Open` 后 `SaveAs`/`Export`。
- **中文路径会被 PowerShell/WPS 读坏**（乱码/「文档打开失败」）：先把源文件 `cp` 到纯 ASCII 路径（如 `{{HERMES_HOME_PARENT}}/AppData/Local/Temp/xxx.doc`）再转。
- **WPS GUI 模式会挂起**：全程 headless + `timeout`/限时，跑完 `taskkill //IM wps.exe //F`（及 wpp.exe/et.exe）兜底防残留锁文件。
- 验证真 docx：`python -c "import zipfile; zipfile.ZipFile(p).namelist()"` 应有 `word/`、`[Content_Types].xml` 等条目；旧 OLE 格式 magic 是 `D0CF11E0`。

## 第2步：dump 表格物理框（学会看表格，核心防错点）
python-docx 的 `row.cells` 会把**合并单元格重复返回**同一 `._tc`。必须去重 + 读 gridSpan 才能知道真实格子：
```python
from docx.oxml.ns import qn
def uniq_boxes(row):
    seen=set(); out=[]
    for c in row.cells:
        if c._tc in seen: continue
        seen.add(c._tc)
        gsc=c._tc.find(qn('w:tcPr')); gs=1
        if gsc is not None:
            g=gsc.find(qn('w:gridSpan'))
            if g is not None: gs=int(g.get(qn('w:val')))
        out.append((c,gs))
    return out
# 起点列：用 tblGrid 的 gridCol 宽度累加，或逐格记录 start_col
```
- 每个选项是「**字母框 + 名称框**两个独立并排格」时，一框填字母、一框填名称，**未选框留空**；封面式「标签+单填写格」才写整串「Y ∣ 一般课题」。**不同模板框结构不同，每次都要 dump 确认，禁止套用上次的坐标**——这是用户反复纠偏「挤一个框里」的根因。
- 纵向合并格（vMerge）：填 r2 即生效 r2/r3，dump 时要标出。
- **vMerge 行对（R2「否」行 / R3「是」行）填值的顺序坑**：选项值格（窄字母格/宽名称格，如类别 Y/一般课题）往往**纵向 vMerge 跨 R2↔R3 共享同一物理格**，而「否/是」单选值格与代码格（col24/col28 那组）才是 R2/R3 各自独立。正确填法：①vMerge 共享的选项值格**只写一次**（写到 R2 或 R3 任一行即同时生效两行，写到哪行不影响结果，但两行重复写/一行写另一行清空会互相覆盖导致值消失）；②「否」行（R2）的选项值格保留官方印刷体「否」「无需填写代码」，「是」行（R3）的选项值格写「是」+实际选题码（类别字母+三位指南号，如 Y085）——**两组单选值格是独立的，别写反**；③每轮灌完必回读两行各自 col24/col28 实测文本核验，确认 R2=否/无需填写代码、R3=是/Y0xx，写反=申报数据错误。

## 第3步：逐格填写（继承版式）
- 只写文字，**不碰 run.font / size / name / 加粗**（`run.font.size=None` 即继承模板），版式原样。
- 多活页框分配（按章切分到 N 框）时，章节标题行可按官方模板惯例用加粗/黑体 12pt 点缀、正文宋体 10.5pt——这是「按规定」而非自创；除官方模板印刷体保留项外，不擅自加字体层级。
- **官方版式=模板字体规格，禁止套自创视觉系统**（用户一级纠偏「务必按课题的版式严格来 字体格式 都要按规定来」）：课题官方 .doc/.docx 的字体字号**规定不在文字说明里，而是藏在每个 run 的 `w:rFonts`(eastAsia/ascii) + `w:sz`**。要「升级/重排版式」=**逐 run 对齐官方模板字体规格**，绝不是给文档套深蓝/琥珀配色、换字体、加色块——那是「统一视觉系统」技能管的**非模板**（开题PDF/PPT/导图）才允许的。模板件(申请书/活页)一律按官方模板原字体走。
- **升级前必须先 dump 官方模板字体基准**（见下 dump 法），已填版字体分布用 Counter 对比基准，发现偏差（如正文被改成非官方字体/字号、标题字号不对）才逐 run 修回；**没有偏差就不要动字体**——动=破坏合规。
- 清格用「保留第一段、删多余段、只留第一个 run」；写值 `p.runs[0].text = ...` 或 `p.add_run()`。
  - **空值格/选项格写入静默失败的根因与修复（force_fill 铁律）**：`cell.text = ""` 保留段落结构不清隐藏 run，后续 `p.add_run` 在 vMerge 空值格/选项格会**填不进**（dump 看是空的）——根因是该格首段已有隐藏 run，`p.text=""` 不删它，新 run 被吞。修复＝**强制清空重建**：删掉该格所有非 `w:tcPr` 子节点，再 `cell.add_paragraph()` 建新段 + 新 run 写字。
    ```python
    def force_fill(cell, text, size=10.5):
        tc = cell._tc
        for ch in list(tc):
            if ch.tag != qn("w:tcPr"): tc.remove(ch)
        p = cell.add_paragraph()
        r = p.add_run(text)
        r.font.size = Pt(size); r.font.name = "宋体"
        if r._element.rPr is None: r._element.get_or_add_rPr()
        rf = r._element.rPr.find(qn("w:rFonts"))
        if rf is None:
            rf = r._element.rPr.makeelement(qn("w:rFonts"), {}); r._element.rPr.append(rf)
        rf.set(qn("w:eastAsia"), "宋体")
        p.paragraph_format.space_after = Pt(0)
    ```
    凡向「空值格/选项格/vMerge 续格」写内容，一律用 `force_fill` 而非 `cell.text=""`；填完必重读 docx 核验各格非空（`[c.text.strip() for c in uniq(row)]`），不 dump 核验就交付 = 串格事故。
    **多行文本必须按 `\n` 拆成多段**：force_fill 若把含 `\n` 的整串塞进一个段落，Word 里不换行（论证格段落数=1、排版挤成一团）——`text.split("\n")` 逐行 `add_paragraph()`（行间空行=空段），段间距 `space_before/after` 按需要设 0–3pt。
- 选项码、经费（纯阿拉伯数字）、负责人列等按填表说明对应；个人敏感项（出生年月/职称/单位全称/电话/身份证）留「（待填：××）」占位，**不编造**，列清单给用户填。
- 填完 `d.save(OUT)`；若被锁（WPS 占用）报 PermissionError → 先 taskkill 再存，或另存新文件名。

  - 字数：官方提纲若对某段标了硬上限（如「300字以内」），**逐段量去空白字数并卡在上限内**，默认比上限留 ~10 字余量；其余无硬限的段按「写够写深、不灌水」配平，不要凑整。深度优化后字数会漂移，**每次灌 docx 前必须重测各段字数**——重写/优化不等于已合规。
  - **字数硬下限（用户一级纠偏「差太多了 目标 6980 / 都要超过 6900 才行」）**：活页七段总量官方上限 7000，但用户要的是**贴顶**（去空白 6900–6990，不贴顶=半成品被点名）。做法：拿同目录已达标件（如数智体心视活页 6922）作基准标杆，逐段比它扩写；灌进 docx 后**实测去空白总字数必须 >6900 且 ≤7000**。注意两点漂移源——(a) 活页论证格里嵌入的思维导图若带「图注/标签文字」（如「▶ 研究框架思维导图（嵌入活页）」）会被计入字数，**嵌图时图注必须另起独立段落且不计入论证七段总字数**（标签单独成段，或图注字数在配平时预留）；(b) 母版 `re.sub(r'\s','',..)` 量的是纯文本，灌 docx 后加图注段会再多几十字，**灌后必重新实测活页格总字数再判断是否超 7000**。卡区间：论证七段 6920–6990，图注段另计。
  - **「对齐」字数技巧**（用户说"山东字数跟潍坊对齐"/"深度优化到最高级"时触发）：
    1. **量目标**：先读参考文档（潍坊申请书/活页）的论证格，`re.sub(r'\s','',txt)` 量出总字数作为目标（如潍坊申请书 5124、活页 6270）。
    2. **锁上限段**：有官方硬上限的段（如「选题说明 300 字以内」）锁定在 ≤300（默认卡 288），不再膨胀；只靠无硬限的段（选题依据/研究内容/创新之处/预期成果/参考文献）把总量顶上去。
    3. **迭代扩写**：写一版 → `re.sub(r'\s','',line)` 逐段量字数 → 找最大缺口段 → `patch` 加硬内容（政策链/统计门禁/变量操作化/干预机制/研究基础实证底座）→ 再量 → 再 patch，直到总量在目标 ±5% 内或差 <300 字即停（再往上=灌水，官方只要求"翔实/略写"不要求凑数）。
    4. **每次加量必须是实内容**：政策文号、功效参数（α/power/d）、Delphi/CVR 门槛、ANCOVA 门禁、变量操作化、干预机制与追踪细节、研究基础底座（技术/数据/方法学/团队/伦理/制度/实证/课程）——禁止用同义复述或空话凑字数。
  - 红线句（「AI初评→人工终判」「以当地最新官方文件为准」「GB/T 7714—2025」）是固定件，**优化语言时必须保留不能砍**；出 PDF 前用文本 grep 一遍全在。
  - 视觉核验接口可能限流（429）——降级为 `fitz` 文本自检（grep 各段标记/红线句/乱码占位符），明早再补视觉，先保证成品可交。
  - **活页↔申请书一致性**（官方明写「本表与《申请书》表四内容一致」）：活页论证 1–5 段必须与申请书表四 1–5 段**逐字相同**，活页**独有**6 研究基础、7 参考文献两段。写活页时直接从申请书 docx 逐字复制 1–5 段 + 追加活页 6/7，**禁止两份分别扩写**（否则 1–5 段字数不一致、违反一致性）。活页总字数官方硬上限 **≤7000**，只有第 1 段「选题说明」另有「300 字以内」段内上限；灌完用脚本逐段 `re.sub(r'\s','',x)` 比对方才达标。
- **课题名称三处逐字一致（封面 T1 / 数据表 T3 / 活页 T1R0）**：官方活页=申请书「内容一致」硬规含**课题名称字段**。数据表 T3 课题名常残留后缀（「…设计与实施研究/教学范式研究」）而封面/活页不带，三处不一=审查硬伤。交付前必 dump 三处课题名断言 `len({n1,n2,n3})==1`，以封面名为准统一（数据表去后缀、活页对齐）；**改完同一进程内回读确认落盘**（save 后另开 docx 读回同值才算真写入，防 WPS 锁/另存路径错）。
  - **T3 R0 课题名称行可能并排两个值格**（uniq=2：一格已是封面名、另一格残留带「…设计与实施研究/教学范式研究」后缀）——固定 `uniq(row)[1]` 读到的是残留格而非封面名，导致三处一致性断言假阴性。清残留格=按内容定位含「设计/范式/实施研究/教学」后缀的那格单独清空，别 `cells[1]` 盲写；各模板行格数/标签列位置不同（IT版 R0=标签+值 2 格、他版 R7=6 格），值格一律按内容或标签定位，不用固定索引。
  - **一致性比对要含匿名替换维度**：活页 1–5 段与申请书比对前，先把申请书全文做「地名→××」替换（如 潍坊→××）再逐字比；**省份级学术对比措辞（如「与山东省已立项的同类项目相比」）不得单方面改成「本省」**——那属对比对象而非个人信息，改了反而造成 1 字差异破坏逐字一致性（本轮实锤：改了导致申 1432/活 1431 不一致）。判匿名泄漏只 grep 城市/县/单位/人名（如 `潍坊|寿光|李彦明`），省份级对比不在泄漏判定范围。
- **活页匿名地名同长替换保字数（「寿光」泄漏修复法）**：活页是匿名评审件，正文出现真实市名（如「寿光市城区初中」）=泄漏；**申请书（非匿名件）保留真名、活页匿名——两者地名策略相反**。修活页泄漏用**同长替换**（「寿光市」→「某市」，3 换 3）使活页论证格去空白总字数不变、不破坏 6900–7000 贴顶；逐 run `run.text.replace`（保字体格式），跨 run 残留用合并重排；替换后 grep `寿光|潍坊|李彦明|孙家` 归零＋重测活页字数仍在区间。

### 官方版式/字体基准 dump 法（「按规定排版」类任务的测量前置）
- 官方规定字体字号在模板 XML 里：逐段/逐格读 `w:rFonts` 的 `w:eastAsia` 与 `w:ascii` + `w:sz`（`run.font.size.pt`），不靠肉眼。典型值示例（潍坊 2026 模板实 dump）：大标题 宋体 26pt 居中 / 章节标题 黑体 15pt 居中 / 「填写注意事项」仿宋_GB2312 14pt / 填表说明 楷体_GB2312 12pt / 页标记「——活页N——」仿宋_GB2312 12pt 粗 / 正文 宋体 10.5pt(五号)。山东 2026 申请书/活页实 dump：申请书封面 T1 标签格=16pt、**值格须同 16pt**（值填成 12pt=视觉塌陷，Counter 全文比对会报「模板外新增 12pt」）；活页 T1R0「课题名称：」标签=黑体 15pt、值=宋体 15pt；承诺页 16pt 属官方原有非异常。已填件做「官方模板 vs 已填 字号分布」Counter 差集，只修模板没有的新增字号。**每个模板数字都要重 dump，禁止套旧模板的数**。
- 已填版偏差检测：Counter 统计全文 run 的 `eastAsia`/字号分布，与官方模板分布比；已填部分出现模板没有的字体（如 宋体默认成了别的、出现 12pt 而官方 10.5pt）即逐 run 修回官方值。
- 附件类文件（选题指南/管理办法）grep 正文无字体明文 ≠ 无规定——规定藏在模板件自身；判定顺序：模板 run 属性 > 文字说明 > 惯例。

### 多活页框分布合规（「——活页N——」分框模板）
- 官方活页模板常为 **N 个独立论证框**（各对应一个「——活页N——」页标记）。论证全文必须**按章分配到 N 框**（如七章活页：活页1=选题依据+研究内容，活页2=思路方法+创新，活页3=预期成果+研究基础，活页4=参考文献+说明，按官方框容量配平），**严禁全堆活页1 而活页2/3 留空**（打印后空页=版式事故），也禁止残句散落到尾框（如参考文献断条落在最后一框顶部）。分框时按官方章节标记（`^[一二三…七]、`）切分，每框以章为最小单位不拦腰断章；尾框只放官方模板本就印在该框的印刷体说明。
- 分框后逐框验：各框字数合计=总字数（去空白）、官方印刷文字（提纲/说明/页标记）逐字保留未动、字体分布与官方基准一致。

## 第4步：转 PDF 渲染 + 视觉核验（必须做，不能只查文本）
- WPS COM 导出 PDF；中文路径同样先 cp 到 ASCII。
- **多文件批量导 PDF 循环**：每份单独 `cp <docx> C:/…/Temp/xx.docx`（ASCII）→ 跑 WPS 导出 → 该份 `taskkill //IM wps.exe //F` 清残留锁 → 再下一份。WPS 会锁文件/挂 COM，不 taskkill 就连导第二份可能静默拿回旧 PDF 或 save 报 PermissionError。一次循环只导一份、跑完清场，别在一个 COM 会话里连开多份。
- **例外（已验证 6/6）：ASCII 桥 + `Documents.Open→SaveAs(17)→Close(False)` 可在单个 COM 会话里循环导全部 N 份**：把每份 docx 先 `cp` 成 ASCII 桥文件（`d0.docx…d5.docx`），逐个 `wps.Documents.Open(ascii)` → `d.SaveAs(ascii.pdf, 17)` → `d.Close(False)` → 再 `cp` 回中文交付目录。各文件走不同 ASCII 名不锁不竞争，一个 `Kwps.Application` 会话跑完 6 份全成功，无需每份 taskkill。若看到锁文件/旧 PDF/PermissionError 再退回「一份一 taskkill」的保守法。
- **Word 导 PDF**：`Kwps.Application` + `ExportAsFixedFormat(dst, 17)`；**PPT 导 PDF 用 `KWPP.Application` + `SaveAs(dst, 32)`**（32=PDF；KWPP 的 `ExportAsFixedFormat` 报类型转换错、`SaveAs(dst,17)` 会转出 400×600 竖版压扁 16:9——PPT 一律用 32）。
- WPS 有时把多页合并/降采样（13 页 PPT 导出成 8 页小尺寸）——这是 WPS 导出逻辑问题，**不影响源文件**，用 python-pptx/python-docx 读回源文件核页数/格子为准。
- `pymupdf(fitz)` 打开 PDF → `page.get_pixmap(dpi=150)` 存 png → `vision_analyze` 逐张核验：选项框各填一格未越框、无溢出/错位/乱码、插图未撑破表格。关键行（选项框、成果表、封面）必须渲染亲验。

## 活页嵌入思维导图的图注段不挤论证格总字数
- 用户明令「导图加进活页、不单独成文件」。做法：matplotlib 出 PNG → `cell.add_paragraph()` + `add_picture(width=Cm(13.5))` 嵌进活页七段论证格的**正文末尾**，交付目录**不留单独导图文件**。
- **图注/标签文字计入字数坑**：若在论证格加「▶ 研究框架思维导图（嵌入活页）」标签段，该段字数会并进活页格总字数，导致活页超 7000 上限被用户打回。对标体心视标杆的**正确做法**：图注保留为独立段「图1  ×××五步研究框架（…）」居中加粗，但**图注字数（约 34–37 字）必须在母版配平时预先预留**（源版目标 = 6980 − 图注字数，如源版压到 6944）；灌完 docx 必重测活页格总字数确认 6900<实际≤7000。图本身不占字数（`re.sub` 只数文本）。
- **图位对标体心视（用户「位置也不对」纠偏）**：图插在「图1」题注**之前**（图在上、题注在下），单图放 [研究内容] 段之后；**双图（架构导读＋内容导图）位序见本节后新增「双图」条**；题注段居中加粗。XML 手法：`OxmlElement("w:p")` + `题注段._element.addprevious(new_p)`（after 则 addnext），新段 `Paragraph(new_p, cell)` 后 `alignment=CENTER` + `add_run().add_picture(png, width=Cm(15))`
- **双图（架构导读＋内容导图）位序与防挤格（三轮纠偏终版）**：用户最终指令「框架导图放在研究内容上边、内容导图放在创新之处上边」——「上边」=**放在章节标题段落之前**（`w:p` 流里该标题段的前一个兄弟节点），不是标题之下。终版位序：「图1 架构导读 → 图1题注 → 3.[研究内容]标题 →（正文）→ 图2 内容导图 → 图2题注 → 4.[创新之处]标题 →（正文）」。四个坑：①**题注序号必须与出现顺序一致**（先图1后图2），出现「先图2后图1」评审一眼矛盾；②**图宽 ≤ 页面可用宽**（`sec.page_width−左右边距`，如 14.7cm），架构导读图 15.0cm 超宽触发 Word 自动挤格位移——把 `wp:extent` 与 `a:ext` 的 `cx`/`cy` 统一设 14cm（或等比缩小）；③**图段＋题注段各加 `w:keepNext`** 锁同页——**但 keepNext 必须按 OOXML schema 顺序插到 `w:pPr` 子元素的前部**（`pStyle` 之后、其他属性之前，`pPr.insert(1, kn)` 或 `insert(0, kn)`），append 到 pPr 末尾会被 WPS 静默忽略导致分页不锁（本轮实锤：append 后图仍与题注分页，移前部后生效）；个别套因标题上方剩余页高不够（图+题注整块放不下）仍会分页，把该图等比缩小（如 14cm→12.5cm，cy 同比 8.0→7.14cm）让整块落回同页；④重排后抽含图页 `fitz.get_pixmap(dpi=110)` 渲染＋`vision_analyze` 目检「图+题注同页、题注在图下方、无溢出表格边界、卡片不遮挡」。
- **图+题注相对顺序与移动技巧**：题注段必须在图段**之后**（图在上、题注在下）。lxml 里 `anchor.addprevious(el)` 会按调用顺序逐个前插——若依次 `addprevious(题注)` 再 `addprevious(图)`，结果是 图→题注（正确）；顺序写反即 题注→图（错误）。批量重排后用「完整段落序列 dump（标注 图/题注/小节标题）」核对，**不要用带 startswith 过滤的简版序列判顺序**——过滤会跳过中间正文段，索引错位导致误判。

- 插入 docx 表格正文格：`cell.add_paragraph()` 追加，图片 `p.add_run().add_picture(path, width=Cm(15.5))` 居中，图注用 `w:sz` 设小一号字；插完转 PDF 渲染验证未撑破表格边界/未溢出页面。

### 导图防压字间距铁律（横向卡片流程类导图，本轮 4 轮返工总结）
- 纵向坐标系 `ax.set_ylim(0,70)`（画布拉高优先，别把 5+ 层挤在 56 格内）；**层间距 ≥4 格**：L1标题(66)→L2底座条(52–57)→L3五步卡片(38.5–44.3)→L4子项卡(22–36)→L5门禁/边界条(5.5–18)，每层之间留白肉眼可见。
- 标题下琥珀装饰线**必须画在文字基线下方 ≥1 格**（先算字高再定位，zorder 高于背景），禁止穿字——这是最常见的"压字"首犯点。
- 副标题小字与其下方色条之间留白 ≥3 格；色条内文字上下留 padding 0.5–1 格，不顶边。
- 卡片内文字用「标题行 y+4.0（18pt 白粗）+ 说明行 y+2.2 逐行 -1.5（12pt 浅蓝）」双行布局，卡片高 ≥5.4。
- 复检方法：全图 vision 判定容易被信息密度干扰且**各轮结论会互相矛盾**（一会"没缺字"一会"压字"）——一律 **PIL 裁剪问题区**（顶部 42%、标题区 25%–75% 宽）再 `vision_analyze` 裁剪图，看局部才准。
- vision API 限流（429）时降级：**用坐标计算兜底**（程序化确认 文本 y 与色块顶/底 的像素间距 > 字高），坐标合格即放行，视觉抽检改事后补。
- 导出 240dpi，PNG ≥2800×1800 宽再嵌 docx（`add_picture(width=Inches(5.6))` 居中），保证打印清晰。

### 活页旧图替换（导图重制后换新图）
- 删旧图：遍历 `cell.paragraphs`，`p._element.findall('.//'+qn('pic:pic'))` 非空即整段 `remove`。
- 找图注段（`p.text.strip().startswith("图1")`），`cap.insert_paragraph_before()` 建新段 → 居中（`alignment=1`）→ `newp.add_run().add_picture(新PNG, width=Inches(5.6))`——新图永远插在图注**前**。

- **换图不破坏版式的最稳做法（保留原嵌入位置/图宽，只换 blob）**：不必删段重建——遍历论证格段落，对含 `graphic` 的段，`blip=..findall('.//'+qn('a:blip'))[0]`，`part=doc.part.related_parts.get(blip.get(qn('r:embed')))`，直接 `part._blob=新图字节`；按「下一段题注是否 startswith 图1/图2」区分替换哪张。位置/题注/图宽/keepNext 全不动，最省最安全；换完回读每段 blob 的 PIL 尺寸确认换对。

### 导图（matplotlib 卡片式）视觉质量三要素：字号/配色/防遮挡（用户「字小、配色不给力、遮挡」纠偏）
- **字号**：嵌入式导图正文 ≥17pt、模块标题 ≥22pt、总标题 ≥34pt（旧 14.5/18/30 太小被点名）；卡片内正文行数上限 4 行，超 4 行自动缩字号 `fs=fontsize*(4.2/max(n,4.2))` 并 `lines=lines[:4]` 截断，防顶到标题横幅/越下边。
- **配色**：用户嫌旧灰暗色（#2e75b6/#548235/#bf8f00）「不给力」——换**高饱和六色** 亮蓝#1f6feb/翠绿#2ea043/橙#e8590c/紫#7030a0/砖红#c92a2a/青#0c8599，卡片浅彩底（#e8f0fe/#e6f6ec…）配同系深字（#1a3a6b…）保证对比；箭头用**金色 #f5b301** 提亮，主干/闭环条深蓝 #15376b 压住。色彩编码固定 蓝=目标/评价、绿=方法/机制、橙=实施/工具、紫=评价、红=推广、青=资源。
- **防遮挡**：卡片加高（arch 6.3 / content 4.1）、标题横幅收窄 `band_h_ratio=0.19`、正文首行中心偏移 `line_h*0.9`（非 0.55，否则 4 行时贴横幅下沿）；内容导图中间核心框收窄（core_w≈4.6）左右卡片外移（lcx/rcx 拉开），连线从卡片外沿画到核心框边、`shrinkB` 留白不穿文字；底部底座条与最下排卡片留 ≥0.5 格间隙。重画后先 vision 全图质检（溢出/压横幅/连线穿框/底座重叠）合格再嵌。
- 重画脚本独立成 .py（如 mm_draw_v6.py），多套数据写进 `__main__`；出图后跑 blob 替换法换入 docx，再刷活页 PDF。
- **make_arch/make_content 须参数化卡片几何（长文主题防溢出）**：不同主题卡片文字长度差异大（健康域指标行更长），硬编码 card_w/card_h/gap/wrap_w/fontsize 会顶出卡框。把绘图函数改成带 `card_w,card_h,gap,wrap_w,body_fs` 形参，长文主题单独传窄卡小字（如 card_w=4.4,card_h=6.0,gap=0.75,wrap_w=14,body_fs=16）；卡片正文仍限 4 行、超则自动缩字并截断。出图先 vision 质检 5 卡无溢出再嵌 docx。

## Markdown→HTML→Edge 无头打印 PDF（最高级文档管线，.md 母版批量出可打印 PDF 用）
- 场景：开题/结题成套 .md 要出「可打印、带色带页眉、表格斑马纹、页码」的专业 PDF，比 WPS 转 docx 字面排版可控、质量上限更高。venv 需 `pip install markdown`（无 pandoc）。
- 三步：①写 HTML 生成器——`markdown.markdown(md, extensions=["tables","fenced_code","nl2br","sane_lists"])` + 公文 CSS（宋体正文、微软雅黑标题、`@page{size:A4;margin:20mm 16mm 22mm 16mm}`、顶部色带、`th{background}` 表头、`tr:nth-child(even)` 斑马纹、红线 blockquote）；②Edge 无头打印；③PyMuPDF 加页脚页码。
- **Edge 无头打印铁律**：`msedge --headless=new --disable-gpu --user-data-dir=<每次独立临时目录> --no-pdf-header-footer --print-to-pdf=<绝对路径.pdf> <绝对路径.html>`。两个坑——(a) 循环里连跑多份只有第一份成功（进程/锁），**必须一份一次调用、每次单独 user-data-dir、跑完 `taskkill msedge.exe` 再下一份**；(b) 路径传**原生 `C:\...` 绝对路径**，MSYS 相对/`/c/` 路径不转原生会静默失败（exit 0 但无 PDF）。
- 加页码：`fitz.open(pdf)` 逐页 `page.insert_text((width/2-30, height-24), f"第 {i+1} 页 / 共 {n} 页", fontsize=8)`，`save(garbage=3, deflate=True)` 瘦身。

## 批量灌同模板多套 docx 的 Python 陷阱（本轮实锤）
- **`force_fill` 清空段**：向官方模板的**空值格/选项格**写内容，`cell.text=""` 或普通 `add_run` 会静默失败（dump 看是空）——这些格首段带隐藏 run。必须 `force_fill`（删所有非 `w:tcPr` 子节点→`cell.add_paragraph()`→`add_run` 设宋体10.5+rFonts eastAsia），再逐格重读核验非空。
- **`rf"..."` 前缀字符串报错**：`os.path.join(rf"C:\...", x)` 里 `rf` 前缀 + 反斜杠路径 + 后续拼接会让 `\u` 变 unicode 转义报 `unsupported escape`——纯 Windows 绝对路径用普通 `r"C:\..."` 或普通字符串，别加 `rf`。
- **`re.sub(r"\s",...)` 在 `<<PY` heredoc 里**：`\s` 会被 shell 吃成 `s`；写独立 .py 文件跑，或用 `re.sub("[[:space:]]","",...)` 双反斜杠。母版模块 `__main__` 里自检字数用独立脚本跑，别在 heredoc 里。
- **heredoc 会把中文弯引号「」“”转成直引号 → 精确匹配替换全部 MISS（高频翻车点）**：母版 .py 里存的是弯引号，`rep(old, new)` 的 `old` 模式经 `<<PY` heredoc 传入时弯引号被转正引号，`old in txt` 为 False，替换静默不生效（打印 `[MISS]`）。**凡对母版做含中文标点（弯引号/破折号「——」/「」）的字符串精确替换，一律写独立 .py 文件再跑，不用 heredoc 传中文模式串**；heredoc 只用于纯 ASCII 逻辑或跑文件路径。批量压字数尤其要遵守（压字数=对母版大量含弯引号句子做 replace）。
- **WPS 中文路径 COM 读坏**（乱码/文档打开失败）：批量导 PDF 前把每份 docx 先 `cp` 到纯 ASCII 路径（`{{HERMES_HOME_PARENT}}/AppData/Local/Temp/wps_<key>.docx`）再走 `Kwps.Application`，PDF 存 ASCII 后 `cp` 回中文交付目录；每份单独 COM 会话 + 跑完 taskkill。

## 课题数据表精确填写规范（全网学习固化 2026-09-30，山东官方15条+实务）
- **核心原则**：选项格"字母+名称"必须**逐项**拆到独立并排格（如"Y ∣ 一般课题"写进对应单选框，未选留空），不是整句写在一个格；选项代码格式严格 `字母∣名称`（全角竖线），限报1项的格只填一个选项。
- **山东申请书数据表 15条规定**（官方"填写数据表注意事项"）：
  1. 课题名称 ≤40汉字（含标点）；2. 关键词 ≤4个、词间空一格；3. 学科分类限报1项（A教育基本理论…V其他，跨学科按主学科）；4. 负责人须能承担实质研究；5. 课题类别限报1项（Z重点/Y一般/QZ青年重点/QY青年一般/DZ对口支援）；6. 是否参照选题指南：选"否"则代码格留空（模板自带"无需填写代码"是印刷体保留）；选"是"填"Y070"式（前缀字母=类别码+后三位=指南编号）；7. 担任导师限报1项（A博导/B硕导/C未担任）；8. 工作单位按公章全称；9. 所在市限报1项（A济南…P菏泽）；10. 所属系统限报1项（A教育部直属…K其他，中小学填E中小学校）；11. 电话/邮箱必填；12. 主要参加者不含负责人/单位领导/后勤；13. 预期成果＝公开发表的专著或研究论文，**成果形式列必须用官方成果类型码**（A专著/B译著/C研究论文/D研究报告/E工具书/F电脑软件/G其他，如「D∣研究报告」，不是「研究报告」这类自由文本；多成果清单+完成时间放活页成果小表 R3–R6 逐行，申请书 T3 R21 是选项格窄格=类型码字母/宽格=类型名称，不塞清单）；14. 经费万元阿拉伯数字；15. 页数不够可加页。
- **邮编规范**（全网核过）：寿光市通用 **262700**；孙家集街道 262700；不要凭记忆写 262729/262711 等街道细分码——除非学校明确有专用投递码，否则填市级 262700 最安全。
- **山东 T3 逐行格位映射**：详见 `references/sd-t3-datum-row-map.md`（R0-R22 每行 uniq P 索引 + 填法），批量灌多套时先 dump 模板行结构再对照此表，不凭记忆套坐标。
- **选项行「字母格+文字格」双独立格铁律（山东数据表 R2/R7 实锤）**：山东申请书数据表 T3 的选项行（课题类别、学科分类、是否参照选题指南、所在市、所属系统）每行是**多个「值格」并排**：窄格（gridSpan 小，2 格）填**字母码**（Y/F/G/E），相邻宽格（gridSpan 大）填**名称文字**（一般课题/课程与教学论/潍坊市/中小学校），二者是**两个独立并排物理格**，不是写整句「Y∣一般课题」塞进一个格。dump 时按 `uniq_boxes` 的 gridSpan 区分：gridSpan=2 的小格=字母，gridSpan≥4 的格=名称；「是否参照选题指南」行的「否/是」印刷值与「无需填写代码/填写选题代码」也是独立格。填完逐格重读核验：窄格只有字母、宽格只有文字，标签格（如「课题类别」「所在市」「所属系统」）保留官方印刷体不动。**填不进的症状＝用 `cell.text=""` 或普通 add_run，必须用下方 force_fill（清空非 tcPr 子节点重建段+run）**。
- **地址规范**："寿光市孙家**集**街道第二初级中学"——7月版潍坊申请书写"孙家集"，9月版山东申请书写"孙家街"，**两处不一致是高危**；须向学校核实公章上的正式名称后统一。
- **填写流程铁律**：填表前必须 ①dump 官方模板每行每列的 gridSpan/vMerge（用 uniq_boxes 函数）；②把官方填写说明逐条对应到物理格；③每格只写文字不碰 run.font；④选项格逐格拆；⑤转 PDF 渲染逐页目检；⑥与活页/申请书交叉核对字段一致。
- **待核实清单（不凭记忆）**：出生年月日、行政职务、专业职务（中级？）、学历学位、电子邮箱、电话、身份证号——隐私项列清单给用户，不代填；但已填过的历史数据（如潍坊7月版）可复用。
- **参加者表行数硬限制（结构坑）**：官方数据表「主要参加者」区是**固定行数的数据行**（山东 T3 = 8 行），紧随其后是「预期最终成果」行与「配套资助经费/预计完成时间」行，二者是独立结构行。填参加者前必须 dump 全表行数确认参加者区边界，**任何参加者都不得写进参加者区之后的行**——写进去会污染成果/经费行结构，修复时要逐格清残留并把官方印刷标签（如「预计完成时间」）回填标签格。人数超出官方行数就压缩到行数内或向用户确认加行，不要顺延写穿。
- **参加者不编造（默认红线）**：主要参加者的姓名/身份证号/出生年月/学历全是隐私敏感项——真实名单未知时一律用「【成员N】＋职务＋分工」占位（如【成员1】初中数学教师，分工：建模维度设计），**绝不编造姓名+貌似真实的身份证号**（形式审查会核对名单，假证号=资格事故）。电话字段未知时按官方占位格式写「（单位固定电话：【　　】　手机：【　　】）」，不代填号码。**例外：用户明令「成员全部用虚拟人代替、姓名自造、身份证你自己编一下就行」时，可造通俗虚拟名（张三/李四/王五式）+ 编 18 位虚拟身份证——但身份证末位必须按 GB11643 校验位算法算出合规形态（前6位用真实地区码如 370783=寿光，生日段对齐出生年月字段，顺序码3位，末位=校验位）；虚拟数据仅演示用，交付时明确告知用户这是占位、真实申报必须替换。**
- **标签格保护铁律（值写串格位=高频事故，用户反复纠偏「怎么两个副校长」「把原表弄坏了」）**：数据表里「标签格（官方印刷体：性别/专业职务/最后学位/所属系统/姓名/身份证号…）+ 值格」是**相邻两列**，值格常在标签格**右侧**且 gridSpan 更大。灌值前必须逐格 dump 该行的 uniq 顺序，**只对值格（空的、在标签格后）写值，标签格一字不动**；同一行把同一值写进两格、或把值写进标签格，症状=并排重复值（「副校长 副校长」「本科 本科」）+ 官方标签丢失。批量灌多套后，必做「官方标签逐字保留」回读：逐行比模板 vs 已填，凡模板有字而已填不同的格，区分两类——合规填入（模板空值格被填）与**误顶标签格**（模板是印刷标签、已填变值）；后者把官方标签文本回填回去再保存。参加者表头行（姓名/出生年月/…列头）同属此铁律：表头行任何一格被数据顶掉=表头损毁，必须恢复。
- **vMerge 续格读重误报的甄别**：官方模板部分值格纵向合并（vMerge），`row.cells` 跨行读到同一 `._tc` 文本，dump 会出现「同一值显示两次」——**先区分是真重复（两格同值、标签被顶）还是 vMerge 读重（同一物理格跨行）**：用 `seen` 按 `id(c._tc)` 去重后数唯一物理格数；唯一格里同值出现 2 次=真重复要修，跨行同一 `._tc` 返回同文本=vMerge 正常现象不用修。

## 多套同模板课题批量生产（同官方模板 × N 学科/选题）
- **同一主持人的个人信息项跨套必须一致**：同一人（如李彦明）灌 N 套申请书时，其行政职务/专业职务/学历/学位/单位等个人字段在所有套里必须同值（如行政职务统一=副校长）。按学科给每套填不同职务（教学主任/教研组长/副校长）= 评审逻辑硬伤；交付前用终检脚本断言三套该字段相等，不一致时以用户指定或真实职务为准统一改齐。
- 场景：用户要「给英语老师做山东课题、姓名留空」并追加「语文课题、数学课题」——同一套官方模板（申请书+活页）灌 N 个不同选题/学科。做法：**写一个通用填充脚本** `fill_three.py`，参数化 {content母版模块, 课题名, 关键词, 选题代码, 选项值, 导图PNG}，循环灌 N 套，**导图 PNG 各自生成后 `add_picture` 嵌活页不单独列**。
- **母版段自带编号前缀时，拼接禁止再加裸标题（标题重复两次 bug）**：母版 S1/H6 等段文本常已自带「1.[选题说明]」「6.[研究基础]」编号前缀，若拼接活页/申请书论证段时又拼「[选题说明]\n{S1}」，每个标题就出现两次。**拼接前 dump 各母版段前 12 字核对是否已带前缀**：带了→直接 `{S1}\n\n{S2}` 纯拼接；没带→由脚本补标题。灌完 grep 各标题关键词（选题说明/选题依据/研究内容）出现次数必须=1。
- **content 母版分模块存 .py**（每学科一个 `sd_<学科>_content.py`，内含 S1–S6 申请书六段 + H6/H7 活页独有段），脚本 `importlib.util.spec_from_file_location` 按学科动态加载——母版可独立迭代扩写字数，脚本只负责灌模板。**对母版做字符串替换（压字数/删句）后必须重新 import 并逐段打印前 30 字核对段头无残留**（删文献编号错位会把「H7 = ]」混进段首、编号 5./7. 漏号，这类损坏肉眼查母版查不出，灌完才在 docx 里现形）。活页七段 = 申请书 1–5 段逐字复制 + 活页 6（研究基础）+ 7（参考文献），每套的 S1–S5 写一次、活页直接引用同一字符串，**保证活页 1–5 与申请书逐字一致**（官方硬规）。
- **选题代码据实查官方选题指南 .wps**（附件1），不凭记忆编：指南条目有编号（如 085 教师跨学科素养 / 053 跨学科课程改革 / 070 人工智能学科融合），「是否参照选题指南=是」时填**编号**（如 085），代码前缀字母=课题类别码；自拟非指南条目才选「否」留空。指南是 .wps 原件需先 WPS COM 转 docx 再 grep 条目。
- **姓名留空模式**：用户说「姓名空着、别的按最高标准」——数据表负责人姓名/性别/出生日期/行政职务/学历学位/工作单位/邮箱/通讯地址/邮编/电话/身份证**全部留空**（不写「（待填）」占位，就空格），只在交付时列「待你补的 8 处个人信息」清单；论证/活页照写满。活页匿名替换 `anon()` 仍把申请人姓名/身份证/邮箱/邮编替换为空格。
- **跨套 copy 前先验同域（体心视≠数学克隆坑）**：N 套并平行成时，若要为「新主题」复制某一套文件当模板，先 dump 该主题自己的课题名+学科分类确认它是否真与源套同一内容域——名字相近的套（如「数学数智融合」vs「数智体心视」）可能是**完全独立的另一域课题**（学科 C｜教育信息技术、健康画像，不是数学 F）。误把邻套 `cp` 成新主题=课题名/论证/选项码/成员全错。正确做法：恢复新主题自己的历史归档版为基底再逐格升级，不克隆邻套；只有确认同域才可直接 copy。

## 修改已交付文件的闭环（用户「怎么还没改/还是原来的样子」类投诉）
- 用户看的是**已渲染的 PDF/交付目录里的旧文件**，脚本改完没重导 PDF、或改动没 save 到交付路径，都会表现为「还是原来的样子」。每次改完必须**同一轮内**：save 到交付 docx → 重导该文件 PDF（WPS ASCII 桥）→ 回读 docx 实测改处 → 简短汇报。改母版/脚本不算完成，落到交付目录才算。
- 用户说「深度解析/深度对比原表」时，做法：官方模板 docx vs 已填 docx 三查——①表数/行数列数逐表比（结构没坏=全一致）；②官方印刷标签逐字保留（模板有字而已填不同的格逐个定性）；③字体 Counter 分布比基准（异常字号/字体才修，官方原有字号如 16pt 承诺页不算异常）。结论先行报「结构坏没坏+哪几处值写串格位+已修到哪」。
- **交付前全量终检矩阵（用户「全面深度优化/务必申请级」时，逐项全绿才交付）**：跑一份脚本对每套输出——①结构：官方模板 vs 已填 逐表 rows/cols 全一致；②官方印刷标签逐字保留（性别/专业职务/最后学位/姓名/身份证号…）；③主持职务三套统一；④课题名称三处一致；⑤活页去空白字数 6900–7000；⑥活页双图=2 且位置正确；⑦活页匿名泄漏 grep 归零（寿光/潍坊/李彦明/孙家）；⑧封面/正文无模板外 12pt 字号残留；⑨红线句（AI初评→人工终判/官方文件为准/GB/T 7714）在申请书＋活页各 grep 一遍。全绿后必刷 PDF（docx 改了要重导，否则交付的是旧 PDF）再报。
