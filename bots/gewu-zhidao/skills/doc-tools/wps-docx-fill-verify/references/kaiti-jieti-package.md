# 开题/结题材料包 · 成套交付清单

课题「开题准备」或「结题交付」成套文件（Markdown 母版落盘，可再转 Word/PPT）。文件名用 NN_ 前缀排序，全落课题目录下。

## 开题包（7 件）
1. `01_开题报告.md` — 12 节：背景/文献空白/概念界定/目标/研究内容(四子问题递进闭环)/方法/创新/计划甘特/预期成果/研究基础条件/经费/评审意见留白。甘特与申请书签字表一致。
2. `02_开题会议材料包.md` — 通知模板、专家意见表、签到表、会议记录表、分工表、进度跟踪表、风险预案表。
3. `03_知情同意书模板.md` — 未成年人：可随时退出不受影响、SID 匿名、保存期限、伦理审查批件号占位；「以学校伦理审查委员会批准文本为准」。
4. `04_过程记录模板.md` — 课堂观察表/作品分析表/访谈提纲/数据台账(SID 主表+加密密钥表分离)/DBR 迭代日志/归档命名规范。
5. `05_成果五件套_初稿骨架.md` — 按申请书「预期研究成果」表逐件：大纲+已填骨架段落+时间线总控+合规红线自查（数据回填后直接成稿）。
6. `06_开题PPT_*.pptx` — 13 页 16:9 学术风（封面/提纲/背景四断层/文献三空白/概念/框架/方法/创新/甘特/成果/伦理/风险/致谢），python-pptx 生成，venv 需 `pip install python-pptx`。
7. 渲染核验 — PPT 转 PDF（KWPP 导出可能丢页/降采样，以 python-pptx 读回源文件页数为准）+ 抽页 vision 核验。

## 结题包（同骨架反向）
结题报告（六段对齐申请书论证，查重<15%，数据带版本戳）、成果逐件成稿版、成果佐证（量规信效度报告/案例库目录/统计输出）、归档清单（对应 04 命名规范）、推广/成果发表标注「××课题成果（批准号）」。

## 合规红线（每套材料成稿前逐条过）
- [ ] AI 评分/量规类一律「AI 初评→人工终判」，不假装终审；
- [ ] 政策/课标引用标「以当地最新官方文件为准」；
- [ ] 未成年人数据 SID 匿名，发表件无可识别信息；
- [ ] 活页类材料匿名：姓名/单位/城市/前期成果名/刊物名全清零（城市写「××市」），成果表活页版无负责人列；
- [ ] 数据每条带可核查来源与版本戳，禁止无来源数字；
- [ ] 查重内控 <15%。
