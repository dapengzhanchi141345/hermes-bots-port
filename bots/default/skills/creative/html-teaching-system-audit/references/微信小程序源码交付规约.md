# 微信小程序源码交付规约（小橙看班类 · 班级管理工具）

适用：李老师要"可发布给真学生用"的微信小程序（班级管理、考勤、通知、课表类）。默认先做**本地存储版**（wx storage 零服务器），升级路线写进 README。

## 目录规约

```
小程序源码/
├── project.config.json   # appid 用 touristappid（测试号），libVersion 按需
├── app.js / app.json / app.wxss
├── utils/store.js        # 唯一数据读写入口（见下）
└── pages/<name>/{js,wxml,wxss,json}   # 四件套
```

- `app.json`：tabBar ≤ 5 项；pages 全部列出（漏注册 = 页面白屏）。
- `app.wxss`：全局主题变量按**玄金红**配色（玄黑 #0d0b10 底 / 宣纸白 #f4efe2 字 / 亮金 #e0b341 强调 / 绿 #5fa87f 完成 / 朱砂 #b23a2e 警示），护眼备选 A 暖墨黑 #17120b。同一项目全程一致。

## 数据层设计（可升级性核心）

`utils/store.js` 是全项目唯一数据读写入口：
- 每类数据一对 `listX / saveX` 函数，读写 `wx.getStorageSync / setStorageSync`（try/catch 包裹）；
- 种子数据内置（演示班级/学生/通知），首次读空时自动灌入；
- 未来换云开发**只改这一个文件**（storage 换 `wx.cloud.database()` 同名方法），页面零改动——这是李老师最关心的可升级性，写进 README。

## 功能增强套路（对标同类工具的升级点）

- 批量导入：逗号/换行分隔 + 去重（按姓名 Set 判存）；
- 可编辑课表：点格子改课、可清空单格，按班级独立存储；
- 秒级倒计时 + 到点 `wx.vibrateShort()` 震动（timer 页设 `_vibbed` 防重复震动）；
- 考勤三态（到/缺/迟）+ 一键全员到 + 缺勤统计 + 近 N 条历史回看；
- 通知双类型（全屏/普通）+ 定时任务（picker mode=date）+ 未读角标 + 三档筛选（我发布/全部/定时）+ 详情页回复；
- 首页五宫格 + 考试倒计时悬浮卡 + 班级切换。

## 自检（每页四件套齐全后跑）

1. 所有 `.json` 逐一 `json.loads` 可解析；
2. 所有 `.js` 过 `node --check`；
3. `app.json` 的 pages 与目录逐一对账（漏注册 = 白屏）；
4. WXML 里 `wx:for` 必有 `wx:key`、`bindtap` 等绑定事件函数名在对应 js 里存在。

## README 必含

导入步骤（微信开发者工具 → 导入目录 → 测试号 AppID）、功能对照表（原版 vs 升级点逐条列）、升级路线、**已知边界**（写死的数据/演示态说明，诚实列出）。

## Pitfalls

- 写死局域网 IP → 换教室/换网就失效；永远运行时探测。
- `setInterval` 只建不清（倒计时/轮询页）→ `onHide/onUnload` 必清，多页切换会叠多个定时器，页面无限吃 CPU。首页悬浮考试卡与 exam-clock 页都要清。
- 演示态数据（老师名/班级名写死）不说清楚 → 交付时在 README「已知边界」写明，云版接登录态后再改。
- WXML 数据绑定里写复杂表达式（嵌套三元 + 对象取键）→ 小程序渲染层支持有限，复杂逻辑移到 js 算好再绑。
- 小程序 `wx.showActionSheet` 的 `res.tapIndex` 越界（把最后一项当清空键时）→ 用数组长度判断 `tapIndex >= len` 兜底，别写死下标。
- tabBar 超过 5 项或 pages 漏注册 → 导入即报错/白屏，自检第 3 步对账防住。
- 把「发布通知」说成会真推给学生 → 本地存储版没有推送能力，README 明确写清楚，云版 + 订阅消息才有（订阅消息需用户先点过一次订阅、模板走审核）。
