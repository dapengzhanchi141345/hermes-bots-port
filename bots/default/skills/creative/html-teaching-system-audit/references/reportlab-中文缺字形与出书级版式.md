# ReportLab 中文字体缺字形与出书级版式量化（Windows 教学 PDF）

做本用户「出书级」教学 PDF（合订本/导学单/配套练习）时，用 reportlab + 系统中文字体生成。本文件记录缺字形清洗、版式量化、思维导图绘制与数据驱动全册生成的规范。生成前必读母版量化值（主技能第 0 步「先学样板」）。

## 中文字体缺字形规律（出书级零豆腐块）

Windows 四套中文字体（`simhei.ttf` 黑体 / `simsun.ttc` 宋体 / `simkai.ttf` 楷体 / `simfang.ttf` 仿宋）的 GBK 字形集有系统性缺字形区，缺字形渲染成空字符 `\x00`（肉眼豆腐块）。出书级要求零豆腐块，生成器必须带「字形清洗层」。

**缺字形高发区（必须替换或改写）：**
- 圆圈数字 ⑪⑫⑬⑭（U+246A–U+246D）：只有 ①–⑩（U+2460–U+2469）有字形，⑪ 起全缺 → 改写中文数字「十一/十二/十三/十四」。
- 下标数字 ₀–₉（U+2080–U+2089）：全缺 → 改写普通数字 `log2`/`log10`。
- 上标数字 ²³⁴⁵⁶⁷ⁿ（U+00B2/U+2077/U+2076/U+2074/U+2075/U+207E）：缺 → 改写 `^n` 形式。
- 数学符号：÷（U+00F7）缺 → 中文「除以」或 `/`；−（U+2212 MINUS）缺 → ASCII `-`；⌈⌉（U+2308/U+2309 取整）缺 → `[]`；≠≤≥≈ 部分缺 → 统一改写中文「不等于/小于等于/大于等于/约」。
- 箭头/装饰：▶（U+25B6）缺 → ★（U+2605 黑体有）；⚠（U+26A0）缺 → `!`；⭐（U+2B50）缺 → ◆（U+25C6 黑体有）；★ 黑体有但保守改 `*`；√× 黑体有保留；→（U+2192）缺 → `->` 或中文「到」；↑↓ 缺 → 「上/下」。
- 引号/括号：『』（U+300E/300F 白角引号）黑体**有**保留；「」保留；　（U+3000 全角空格）保留；＋＝／＞（全角 U+FF0B/FF1D/FF0F/FF1E）缺 → ASCII +/=/</>

**清洗层（生成器统一调一次，题目区与解析区都要过——子代理产出的解析文本常含 ₂ ⁿ ÷ − 等缺字形）：**
```python
def clean(t):
    if not t: return t
    t = str(t)
    t = t.replace("log₂","log2").replace("log₁₀","log10").replace("log₂₁₀","log210")
    t = t.replace("₂","2").replace("₁₀","10")
    m = {"−":"-","²":"^2","³":"^3","⁴":"^4","⁵":"^5","⁶":"^6","⁷":"^7","ⁿ":"^n",
         "＋":"+","＝":"=","／":"/","＞":">","＜":"<","≠":"不等于","≤":"小于等于","≥":"大于等于",
         "÷":"除以","⌈":"[","⌉":"]","→":"->","↑":"上","↓":"下","　":" ",
         "⑪":"11","⑫":"12","⑬":"13","⑭":"14","⑮":"15","⑯":"16","⑰":"17","⑱":"18","⑲":"19","⑳":"20",
         "✔":"√","✘":"×","≈":"约","★":"*","☆":"□","⚠":"!","▶":"★","⭐":"◆","▍":"■"}
    for a,b in m.items(): t = t.replace(a,b)
    return t
```
对 `q/options/answer/explain/_deep_explain` 全部字段调用 `clean()`。

**验证（生成后必做，出书级=空字节 0）：**
```python
import fitz
d = fitz.open("out.pdf")
full = ''.join(p.get_text() for p in d)
tofu = full.count(chr(0))
print(f"页数:{len(d)} 空字节:{tofu}")
# 定位: 对每个 chr(0) 取前后 12/8 字符, 反向查源 JSON 哪个字段哪个源字符
```

**字形普查（写 clean 前一次扫全数据源，别靠逐页试错，快一个数量级）：**
```python
import unicodedata
for ch in set(all_text):
    if ord(ch) < 128: continue
    if unicodedata.category(ch).startswith("L"): continue   # 汉字/字母保留
    if ch in "。！？，、；：（）《》【】「」‘’“”—…·√×≈≠≤≥±∞%‰℃°": continue
    print(f"U+{ord(ch):04X} '{ch}' {all_text.count(ch)}次 {unicodedata.name(ch,'?')}")
```
按统计逐个决定替换。

## 出书级版式量化（对齐 workbuddy 八年级合订本母版）

用户既有旗舰样板 = workbuddy 八年级三套合订本（教学设计 263p / 导学案 216p / 配套练习）。做任何新课件 PDF 前先扒母版量化值。

**配色体系（母版实测 hex）：**
- 教学设计：深棕蓝 `#17375E`（分节条/主标题）/ 藏蓝 `#1F4E79`（环节条）/ 金黄 `#BF8F00`（★目标）/ 砖红 `#C0504D`（子分节）/ 深红 `#C00000`（! 预设）/ 灰 `#595959` / 深灰 `#333333`（正文）/ 浅蓝点缀 `#2E75B6` / 卡片底 `#F4F6FA` / 线条 `#D9E1EC` / ◆装饰金棕 `#C58F2E`。
- 导学案：藏蓝 `#1F4E79`（站卡反白底）/ 浅蓝 `#EEF3FB`（科学依据框底）/ 中蓝 `#8FAADC`（站卡副标题字）/ 橙 `#C55A11`（提示/进阶关）/ 绿 `#2E7D32`（基础关）/ 表头浅蓝 `#E8EDF5`。
- 配套练习：深蓝 `#1F4E79`（关卡条/解析区标题反白）/ 浅蓝 `#EAF3FA`（表头底）/ 中蓝 `#8FAADC` / 金黄 `#BE9000` / 解析标签紫 `#6A1B9A` / 正文 `#333333` / 灰 `#595959`。

**字号与段落（量化）：**
- 封面主标题 26–30pt 黑体居中；副标题 13pt；装饰行「◆ ◆ ◆ ◆ ◆ ◆」9–11pt；封面信息 9.5pt 楷体；设计者行 9pt。
- 课标题 15–16pt 黑体**居中**（用户明确要「标题课时居中」）；课程信息行 8.5–9pt 楷体居中，竖线 `｜` 分隔（教材位置｜课时｜课型）。
- 正文 9pt 仿宋（行距 14）；强调 9pt 黑体；关卡/站标题 11–13pt 黑体反白条（白字）；解析正文 9pt。
- 表格 8.5pt，表头底纹浅蓝 `#E8EDF5`/`#EAF3FA` + 黑体字 + 主色文字；网格 0.4pt `#BBBBBB`；单元格 padding 左右 5 / 上下 3。

**结构铁律（模板不可擅改——用户原话「不能变了 我看的不舒服」）：**
- 配套练习 = 题目区在前（9 关卡，零答案，选项 A C / B D 两列横排，填空 `____`、判断 `（ ）`、简答横线留白）+ 册末独立《参考答案与深度解析》区（每答案开头「题号 答案」，下挂 5 标签【考查点】【解题思路】【逐项剖析】【易错警示】【方法点拨】，标签紫 `#6A1B9A` 底纹条）。**题目与解析必须分册/分区，不得混排**（用户铁律「题目和解析是分开的」）。
- 导学案 = 页眉 `◆ 课题名 ◆` + `— 页码 —`；深蓝课号条「第 N 课 · 导学单」白字居中；大标题居中；素养维度表（信息意识/计算思维/数字化学习/社会责任）；7 站通关（藏蓝反白站卡 `● 站N 标题 副标 · 时间` + 浅蓝 ◆科学依据框紧贴）；站内容严格配套教学设计 14 段式（goals→素养表、focus/difficult→站1/站3、knowledge→知识速记卡、activities→站4、exercises→站6 三档、站7 费曼输出 + 学后反思三问 + BKT 自评 + 记忆加固 + AI 边界 + 下节预告）。
- 教学设计 = 14 段式；⑦ 教学过程用四栏表（步骤/教师活动/学生活动/设计意图）；⑦-2 课时思维导图 = 真绘制彩色树图（非「见附录」占位）；⑩ 前沿用最新年份数据；⑪ 跨学科四栏表（关联学科/融合内容/课堂落点）；⑫ AI 五级框架 L1–L5 + OECD 铁律「表现≠学习」；⑭ 尾部「课末检索卡·隔日自测三问」（明日/七日/廿一日）+ 1-2-7-21 间隔；页眉 `◆ 课题名 ◆` + `— 页码 —`；封面 `◆◆◆`+「优秀教学设计全册合订本」+ 六单元三十课时 + 课标依据行。
- 全册 30 课（用户明确「8 课时是学校安排，我要整册」），非 8 课时。

## 思维导图绘制规范（reportlab 彩色树图）

母版 ⑦-2 思维导图是**真绘制的彩色树状图**（中心蓝框 + 左右分支 + 蓝/绿/橙/紫编码叶子），非占位文字。用 reportlab `Drawing` + `Rect/String/Line/Path` 绘制，画进教学设计 ⑦-2 段。

**布局铁律（避免「不理想」的常见坑）：**
- 中心框严格居中（`cx=w/2, cy=h/2`），深蓝实底白字（视觉权重强），约 40×12mm、11pt 黑体。
- 分支左右严格对称：`n` 个分支，左 `ceil(n/2)` 右 `floor(n/2)`；同侧分支按 y 从上到下排布，间距 = `h/(m+0.4)`。
- 分支框 x 偏移 `BX=52mm`（内移让出叶子列），叶子列 x 偏移 `LX=92mm`（外移避免与分支框重叠）；分支框 22×9mm 彩色实底白字 8.5pt；叶子 20×8mm 白底彩边 7.5pt。
- 配色编码：分支按主题 蓝 `#2E75B6`/绿 `#5F9E6F`/金 `#BF8F00`/红 `#C0504D`/紫 `#7030A0`/青 `#1B8A8A` 循环，叶子边框同分支色。
- **连线不交叉（关键坑）**：中心→分支用单段 S 形贝塞尔：`p.moveTo(x1,cy); p.curveTo(x1+(x2-x1)/3, cy+(y-cy)*0.15, x1+(x2-x1)*2/3, y-(y-cy)*0.15, x2, y)`，同侧上下分支曲线平行不交叉。直角折线或「先水平后斜向三段」会交叉。叶子连线用直线（分支框外缘→叶子内缘）即可。
- reportlab `Path` 属性：`p.strokeColor`、`p.strokeWidth`、`p.fill`（**无** `setStrokeColor`/`setLineWidth`，旧 API 报 `Illegal attribute`）；圆角 `RoundedRect` 在 reportlab.graphics.shapes **不可 import**（无此名），用普通 `Rect` 代替。

**验证**：渲染单页 PNG（`fitz` 取页 `get_pixmap(dpi=150)`），`vision_analyze` 查 7 项：①中心居中 ②左右对称 ③分支彩色实底 ④叶子白底彩边不重叠 ⑤连线不交叉 ⑥文字无溢出/豆腐块 ⑦整体精致。不通过就按「分支内移 + 叶子外移 + S 曲线」调整。

## 页眉课题名动态映射（多课连续生成）

全册 30 课连续生成时，页眉 `◆ 课题名 ◆` 需随课变化：
- `class _LessonMarker(Flowable)`（**必须继承 `reportlab.platypus.flowables.Flowable`**，否则缺 `getKeepWithNext` 属性报错），`wrap` 返回 `(0,0)`、`draw` 空。
- 每课首页 `E.append(_LessonMarker(title))`。
- 自定义 `DocTemplate.afterFlowable(fl)`：`isinstance(fl,_LessonMarker)` 时 `records.append((self.page, fl.title))`。
- `onPage` 页眉函数用 `bisect.bisect_right(pages, doc.page)-1` 二分查最近的不超过当前页的课题名。
- 坑：`onPage` 在每页 build 开始时调用，`afterFlowable` 在该页 flowable 处理后才填记录——「最近的前一个 marker」二分正好兜住同课多页（第 2/3 页沿用第 1 页课题名）。

## 数据驱动全册生成（单一数据源）

三套 PDF（教学设计/导学案/配套练习）共用同一份 `ai_content.json`（课 schema：`title/goals/focus/difficult/activities/knowledge/guide/exercises/expand`），Python 生成器 `gen_all_*.py` 数据驱动，避免手写 30 课。
- 配套练习扩题：子代理产出 `_new_ex_Lxx.json`（每课补 6 题达 10 题）+ `_deep_ex_Lxx.json`（原 4 题五维度解析），先各自 `json.load` 校验 key 齐全、字段完整（q/type/level/options/answer/kp/explain），再合入 `lessons[lid]["exercises"]`（新题 `append`，解析写进对应题 `_deep_explain`）。
- **重复追加坑**：合并前断言当前每课题数（已 10 题则不再 append，截断回前 10）——子代理重跑会重复注入。
- 子代理落盘路径漂移：常写到 `{{HERMES_HOME_PARENT}}\`（家目录）而非工作目录，归位时多路径探测（`~/build_new_ex_*.json`、`build/_new_ex_*.json`）。
- 判断/简答题字段陷阱：子代理有时把答案写进 `explain`、`answer` 留空 → 合并时若 `type in(单选,判断) and answer 空 and explain 非空` 则交换；简答题 `answer` 允许空、`explain` 承载参考要点。
- 题型混合规范：每课 6 新题 = 3 单选 + 2 判断 + 1 简答，难度 基础 2 / 提升 2 / 挑战 2；判断题 `options=['正确','错误']`、简答 `options=[]`。
