# 出书级教学 PDF 合订本（三件套）

为教师教材产出可印刷的 PDF 合订本三件套：**教学设计**（14 段式）/ **自主学习导学案**（7 站通关）/ **配套练习**（9 关 + 册末逐题深度解析）。同一份内容数据驱动整册 30 课生成，配色分书区分，思维导图矢量真画，全篇零豆腐块。

## 什么时候用
- 要为某册教材出 教学设计 / 导学案 / 配套练习 合订本（出书级版式）。
- 量级是整册（30 课 / 6 单元），不是 8 课时精简版。
- 视频类任务不归这里（那边走 `teacher-video-lesson-team`）。

## 铁律（先读母版再动手）
- **先深度学习母版**：把用户放进文件夹的 workbuddy 合订本（docx + 真实渲染 PDF）逐段 dump 出来对齐结构，不要凭感觉套模板——用户反复打回的头号原因。
- 要**整册 30 课**：用户明确「8 课时是学校的安排，我要的是整册」。
- ⑩ 现代科技链接段必须喂**最新前沿**（国务院「人工智能+」行动意见 / 教育部双指南 / 具身智能 VLA / DeepSeek-R1 / 538 款备案 / AIGC 标识制度 / 国家教育数字化战略 2.0「AI 试验场」），不要停在旧数据。

## 流程（顺序固定）
1. **数据先行** — 全部课内容进单一 `ai_content.json`：顶层 `{_meta, lessons}`，`lessons` 是 dict（key 字符串 "1".."30"），每课 `title/goals/focus/difficult/activities/knowledge/guide/exercises/expand`；`_meta.units` 带每单元 `frontier`（最新案例，喂 ⑩）。改内容只改 JSON。
2. **共样式抽模块** — 配色 / 表格 / 思维导图 helper 放 `pdf_style.py`，三份生成器共享。配色分书：设计=深棕蓝 #17375E，导学=藏蓝反白站卡 #1F4E79，练习=紫 #6A1B9A。
3. **写 3 个数据驱动生成器** — `gen_all_design_pdf.py` / `gen_all_guide_pdf.py` / `gen_all_exercise_pdf.py`，都循环读 JSON。重跑即整册再生，不手搓 30 份。
4. **跑通 + 渲染网格 + 文本层断言**（见验证节）。
5. **归档**：成品归 内容中心 课程/ 下，生成器留 build/。

## 双段并行：内容扩写（题量/深度升级时的打法）
- 先把全册题导出单一 JSON（含 q/options/answer/explain/kp），再派 6 子代理（每 5 课一组）并行两段：①给现有题写五维度深度解析；②按 10 题制补造新题（避开现有题）。回写合并进 `ai_content.json` 后重跑生成器，**不要手搓 30 课**。详见 `references/cjk-reportlab.md` 的「新题配比与解析深度」。

## 结构骨架（对齐 workbuddy 母版）
- 教学设计：14 段式（①基本信息→⑭反思）。⑦ 教学过程用 **5 环节四栏表**（教师活动/学生活动/设计意图/评价关注点）+ ⑦-0 导语 + ⑦-1 安全 + ⑦-2 思维导图 + ⑦-3 元认知三问。⑥ 评价含 ⑥-1 量规 + ⑥-2 BKT + ⑥-3 一致性表。⑫ AI 指引含 ⑫-1 六要素 + ⑫-2 升格。
- 导学案：7 站（回忆 JOL → 情境 → 问题链 Q1重点/Q2难点/Q3联结+速记卡 → 动手 → 一图理清 → 闯关三档+错题诊疗表 → 费曼），尾反射三问 + BKT 自评 + 1-2-7-21 记忆加固 + AI 使用边界。每站带 ◆科学依据小字。
- 配套练习：9 关（回忆/基础/提升/拓展挑战+量规/变式/间隔/错题诊疗/星级挑战七要素表/分层），**每课 10 题起**（原 4 题 + 补造 6 题），册末统一收「参考答案与深度解析」，每题配【考查点】【解题思路】【逐项剖析】【易错警示】【方法点拨】五维度深度解析。

## 思维导图必须矢量真画（用户重点反馈）
- ⑦-2 / 站5 导图**必须真画**（reportlab Drawing：中心框 + 左右彩色分支 + 叶子 + 连线），绝不能用「见附录：手绘板书示意图」占位文字。
- 分支按主题配色（蓝 #2E75B6 / 绿 #5F9E6F / 金 #BF8F00 / 砖红 #C0504D）；连线粗 ≥1.5pt，字号 ≥7.5pt，否则印刷糊。
- 数据驱动时导图节点直接取 `knowledge[]`（k=分支名、d=叶子），自动铺 4 分支。

## Windows CJK 字体（出书级零豆腐块）
- reportlab 注册 simhei/simkai/simfang（`C:/Windows/Fonts/*.ttf`），全篇 fontName 用它，禁用默认字体。
- **圆圈数字 ⑪⑫⑬⑭ 在 simsun/simhei/simkai 里缺失（只能到 ⑩）**——分节编号 ⑪ 之后一律写「十一/十二/十三/十四」，别写 ⑪⑫⑬⑭，否则印刷豆腐块（⑦⑧…段最易踩）。
- 缺字形字符（▶ ⚠ ☆ 等）渲染成 `\u0000` 空字节——生成后必须全文断言 `chr(0)` 计数为 0；▶ 换 ★，⚠ 换 ! 。
- 字体注册 / 缺字形探测法 / 文本层验证脚本 / 矢量导图 / 数据驱动生成器细节见 `references/cjk-reportlab.md`。

## 版式量化（出书级）
- 页边距 左/右 24mm、上 20mm、下 18mm；A4。
- 封面：主标题 26-34pt 黑体居中 + ◆◆◆ 装饰条 + 副信息金棕色 + 底部「依据课标 + 设计人 + 单位」行。
- 分节条 12pt 黑体带淡底纹（#F4F6FA）；子分节 10.5pt 砖红；表头渐变底色卡片化 + 圆角 + 0.4pt 网格。
- 页脚：`课题名 · 第N课 · <书名>` 右对齐 + `设计：李彦明｜<单位>` 居中。

## 验证（出书级必做，三项）
1. 渲染整册 PNG（pymupdf `get_pixmap(dpi=72)` 拼网格）→ `vision_analyze` 逐格看：豆腐块 / 分节条底纹 / 表格卡片化 / 配色协调。
2. 文本层断言：`'⑪' not in full`、`full.count(chr(0))==0`、各段标题（「教学过程」「参考答案与深度解析」）计数 == 课数。
3. 页数合理：设计 30 课约 150 页、导学案约 90 页、练习约 70 页（含册末答案）。

## Pitfalls
- 拿占位文字冒充思维导图 → 用户当场打回。真画。
- 圆圈数字 ⑪ 之后没改中文 → 印刷豆腐块。改十一/十二…。
- 生成器按 `A[2]` 取 activities 但某些课只有 2 项 → 越界。生成前 pad 到 3（补一个「综合探究」占位 dict）。
- exercises 里 options 可能为 None / 非字母列表 → 统一按 radio 处理，`if e.get('options')` 守卫。
- 文本层验证 `chr(0)` 是 **必须**项：vision 看不出豆腐块，只有文本层能抓。每课导图/四栏表/量规表跑一遍。
- 停在前旧数据不联网 → 用户要「全网深度学习升级」。⑩ 段联网取最新 2025-2026 案例。

## Verification
- 三份 PDF 生成 exit 0；页数落在区间；`chr(0)` 计数 0；段标题计数 == 课数；`vision_analyze` 网格逐格无豆腐块、版式达标。交付清单：`ai_content.json` + 3 生成器 + 3 份合订本 PDF + `pdf_style.py`，逐项勾。
