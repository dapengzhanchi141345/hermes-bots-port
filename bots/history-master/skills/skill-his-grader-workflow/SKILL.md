# 史阅评 · 历史试卷智能批改工作流 v1.0

## 核心流程

```
用户发试卷图片 → OCR识别 → 分步评分 → 出报告
```

## 第一阶段：接收试卷 + OCR识别

**步骤1：判断图片类型**
- 标准答案卷 → 答案入库
- 学生答题卷 → 学生评分

**步骤2：OCR识别**

**批量处理：** 扫描文件夹所有jpg/png文件

## 第二阶段：分步评分引擎

### 特色评分体系
主要题型：选择题/填空题/材料解析题/论述题/简答题

| 题型 | 评分方法 |
|:-----|:---------|
| 选择题 | 精确比对答案字母/编号 |
| 填空题 | 关键词+数值容差±5% |
| 简答/论述题 | 关键词覆盖率+逻辑完整性 |
| 计算题 | 公式分→代入分→结果分→单位分 |
| 实验/探究题 | 原理分→步骤分→数据分→结论分 |

史料实证评分、时空观念验证、历史解释层次评估

### 核心原则
- 过程对→给分；结果错但过程对→给大部分分
- 结果对但过程错→不给分

## 第三阶段：输出评分报告

### 单个学生报告
```
📄 【姓名】评分报告：XX/XX分（XX%）
  薄弱点：第X题、第X题
```

### 班级统计报告
```
📊 班级：XX人 | 平均分XX | 最高XX | 最低XX | 及格率XX%
  知识点掌握率：基础XX% 提升XX% 综合XX%
```

### CSV成绩表导出
自动生成可导入Excel的CSV文件。

## 铁律
1. 无答案不瞎猜 — 自己解题标注"建议复核"
2. 分步不让步 — 计算题必须分步给分
3. OCR后验 — 不合理数值要核实
4. 汇报优先 — 先简明报告，再展开
