# 格阅卷 · 物理试卷智能批改工作流 v2.0

## 核心流程（三句话）

```
用户发试卷图片
  ↓
我做三件事：
  1. OCR识别（Agnes AI多模态）
  2. 分步评分（四步评分引擎）
  3. 出报告（文字报告 或 生成CSV成绩表）
```

---

## 第一阶段：接收试卷 + OCR识别

### 自动执行（无需用户操作）

当用户发来试卷图片时，我执行以下步骤：

**步骤1：判断图片类型**
- 如果是「标准答案卷」（用户说明或我根据内容判断）→ 执行「标准答案入库」
- 如果是「学生答题卷」→ 执行「学生评分」

**步骤2：OCR识别**
通过Python脚本调用Agnes AI多模态模型：
```python
# 核心调用（自动执行，用户无感）
python3 grader_engine.py --mode ocr --images 学生1.jpg 学生2.jpg
```
识别结果结构：
```json
{"1": "C", "2": "B", "15": "右", "25": "W=Gh=2000×5=1×10⁴J..."}
```

### 批量处理

用户告知文件夹路径时，扫描所有jpg/png文件：
```python
python3 grader_engine.py --mode batch --student-dir ./考场1/ --answer-key ./答案库.json --output ./成绩.csv
```

## 第二阶段：分步评分引擎

### 选择题 — 精确比对
```
学生选C ↔ 答案C → 满分2/2 ✓
学生选A ↔ 答案C → 0/2 ✗
```

### 填空题 — 关键词+数值容差
```
数值匹配：83.3% ↔ 83% → 通过（容差±5%）
关键词：排开液体的体积 ↔ 排开液体的体积 → 通过
```

### 计算题 — 四步分步评分
```
┌─────────────┬─────────────┬─────────────┬─────────────┐
│   公式分     │   代入分      │   结果分      │   单位分      │
│   ~30%      │   ~30%       │   ~25%       │   ~15%       │
│  写对公式    │  代对数值     │  算对数字     │  写对单位     │
└─────────────┴─────────────┴─────────────┴─────────────┘

核心原则：
  过程对→给分 ✓  过程错→扣分 ✗
  结果错但过程对 → 给大部分分（公式+代入+单位）
  结果对但过程错 → 不给分（蒙的）
```

### 实验题 — 四步分步评分
```
┌─────────────┬─────────────┬─────────────┬─────────────┐
│   原理分     │   步骤分      │   数据分      │   结论分      │
│   ~25%      │   ~25%       │   ~25%       │   ~25%       │
│  方法正确    │  步骤完整     │  记录规范     │  表述准确     │
└─────────────┴─────────────┴─────────────┴─────────────┘
```

## 工具链

| 工具 | 用途 |
|:-----|:------|
| `grader_engine.py --mode ocr --images <图片>` | 单张/多张试卷OCR |
| `grader_engine.py --mode batch --student-dir <文件夹> --answer-key <答案库> --output <CSV>` | 批量批改全班 |
| `grader_engine.py --mode store-answers --images <标准答案图片>` | 标准答案入库 |
| `grader_engine.py --mode grade --student-json <答案JSON> --answer-key <答案库>` | 手动评分 |

## 铁律

1. **无答案不瞎猜** — 没有标准答案时，我自己解题给出答案，但标注"建议复核"
2. **分步不让步** — 计算题和实验题必须分步给分，不因结果错而全盘否定过程
3. **OCR确认** — OCR识别结果如果数值明显不合理（如跳绳速度4m/s=14.4km/h远超人类极限），需向用户确认
4. **汇报优先** — 每次批改完成直接输出简明报告，用户说"详细"再展开
