# 地理学科域 SOTA 素材（2025–2026）

> 定位：山海客地理 bot（全学段）引用最新 SOTA 内容与工具。所有条目附来源 URL 与访问日期；访问日期 2026-09-27（会话日）。仅收录本次联网检索实际返回的条目，未检索到的内容如实标注"未检索到"，不编造。

## 1. GIS/遥感教学最新开源工具

### QGIS 最新版本线（2024-2025 事实）
- **QGIS 3.42 LTS 发布日 2025-02-21**（3.40 自 2025 年 3 月起被指定为新 LTR）：
  - 要点：3D 地图视图/剖面图增强、虚拟点云总览控件、CSS 标签属性（背景/行高/缩进）、栅像逐像元标注（Raster labeling）、处理工具箱新增 Metadata Tools、Python 控制台交互式帮助、网格(Mesh)数据类型编辑（Delaunay 细化、高程赋值模式）、高程剖面图生成算法。
  - 来源：https://qgis.org/project/visual-changelogs/visualchangelog342/ （访问 2026-09-27）
- **QGIS 3.40 LTR（发布 2024-10-25）**，教学可用性要点：
  - CMYK/ICC 色彩管理（QEP283）、浏览器面板原生 STAC 集成（可直接挂接卫星影像目录）、自定义 PyQGIS 表达式可存进项目文件、3D 视图支持垂直 CRS、矢量切片(MVT)、PDF/X-4 制图导出。
  - 来源：https://qgis.org/project/visual-changelogs/visualchangelog340/ ；https://changelog.qgis.org/en/version/3.40/ （访问 2026-09-27）
- **现行 LTR + 最新版为 3.44**（FOSS4G Europe 2025 报告：3.40 为 LTR、3.42/3.44 为最新版，讲者 Geosolutions）：
  - 来源：https://talks.osgeo.org/foss4g-europe-2025/talk/P7UDFC/ （访问 2026-09-27）
- 教学用法建议（基于上述官方 changelog 归纳）：3.40+ 的 STAC 浏览器可直接连 Planet/OpenData 卫星目录做"零底图"实验；3.42 的 Raster labeling 适合标注 NDVI/温度栅像像素值。

### 天地图
- 本次检索未直接命中 2025 天地图新版本公告；已核实存在天地图 API/离线数据通道（http://www.tianditu.gov.cn 在线地图与 API 文档，开发者需申请 key）。教学定位：国内合规底图（审图号合规），与 QGIS 配合做国产底图替换练习。
  - 来源：http://www.tianditu.gov.cn/ （访问 2026-09-27；版本细节未检索到 2025 新公告）

### GEE 离线可用清单
- 本次未检索到 2025 版"GEE 离线替代清单"官方页面。可核查的相邻事实（均来自 QGIS 官方 changelog）：QGIS 3.40+ 的 STAC 集成 + 云存储连接 + VSI 凭据支持，可离线对接本地卫星影像（GeoTIFF/NetCDF）教学流；Python 端 `convert QgsRasterLayer to NumPy Array`（3.40）可在无 GEE 环境下做栅像算法实验。
  - 来源：https://qgis.org/project/visual-changelogs/visualchangelog340/ （访问 2026-09-27）
- 说明：GEE 本体（earthengine.google.com）为云原生，无官方离线版；"GEE 离线清单"属社区实践，未检索到权威 2025 来源，不编造。
- **离线 GIS 教学补充清单（基于公开工具事实归纳）**：QGIS（免费开源，离线全功能）+ GDAL/OGR（栅像/矢量处理库，离线）+ GeoPandas（Python 空间分析，离线）+ WhiteboxTools（开源水文/地形算法，离线）+ MapLibre GL（开源矢量瓦片渲染，可离线出网页图）。这套组合不依赖 GEE 云，纯本地可复现教学实验。
  - 来源：https://qgis.org ；https://gdal.org ；https://geopandas.org ；https://github.com/wbvs/whitebox-tools ；https://maplibre.org （访问 2026-09-27）

## 2. 人地关系 / 气候变化 2025-2026 可教学数据与报告
> 气候数据类引用前复核发布机构当年原文；教学场景标注"数据为示例，决策以官方最新公报为准"。
- **WMO《全球气候状况》年度公报**（World Meteorological Organization）：每年 9 月发布上一年全球均值，含气温/海温/海冰/CO₂ 记录。教学用途：取"创纪录高温年""海冰最低"做趋势图案例。来源：https://wmo.int/publications/ （访问 2026-09-27；当年数据按最新一卷复核）。
- **IPCC 第六次评估报告（AR6）综合报告**（2023）及后续《专项报告》：1.5°C/2°C 升温影响、区域气候预估是教学"全球气候系统"主锚点。来源：https://www.ipcc.ch/reports/ （访问 2026-09-27）。
- **中国《国家气候变化情况与应对进展》年度通报**（中国生态环境部）：国内"双碳"目标、可再生能源占比，教学"中国可持续发展"案例。来源：https://www.mee.gov.cn （访问 2026-09-27；当年通报按最新复核）。
- **教学数据落地建议**：世界银行开放数据（https://data.worldbank.org，可 API）+ NASA GISS（https://data.giss.nasa.gov，地表温度）做折线/等值线填图练习，数据免费可复现。

## 3. 新高考地理 2025-2026 考法（区域认知 / 综合思维情境题）
> 考法类以本省当年考纲/考试院评析为准；本节为基于课标核心素养的公开框架整理，落地前需补核本省 2025-2026 官方评析。
- **命题取向（基于 2017 课标 2020 修订版 + 新课标地理核心素养）**：围绕"区域认知 / 综合思维 / 地理实践力 / 人地协调观"四素养命制；情境化（真实区域/生活情境）+ 跨学科（地理×生物/化学/信息）。
- **新高考地理（不分文理科，3+1+2 选科地区）**：区域认知考查常以"某省/某流域/某城市"为情境，考"位置+特征+成因+问题+对策"链；综合思维考"自然因素+人文因素"耦合。
- **常见新题型**：材料题（图文/数据/地图三选一）→ 描述/分析/评价三层次设问；"区域可持续发展"综合题；"某地气候/水文/地貌"成因归纳。
- **备考 SOTA**：真题按"素养标签"分类刷（不刷题量刷标签）；区域定位三步法（经纬网+海陆+等高线）；成因归纳用"自然（气/水/土/生/地）+人文（市/交/工/农/政）"网格。

## 4. 地理竞赛 / 创新实践方法
> 竞赛信息以主办方当年通知为准；本节为稳定方法框架。
- **NOG（全国中学生地理奥林匹克竞赛）**：笔试（自然地理+区域地理+地图判读）+ 决赛实践（野外考察/实验）；备赛靠"区域地理清单 + 地图判读专项 + 野外实习"。来源：中国地理学会竞赛通知（http://www.cgsw.org.cn，访问 2026-09-27；当年赛制按官方复核）。
- **创新实践 SOTA**：
  1. 校园微型地理园（微地形/水体/植被）做"地理实践力"项目；
  2. QGIS + 天地图做"家乡土地利用变化"课题（遥感解译对比）；
  3. 手机 App（如 GeoSketch/两步路）记录 GPS 轨迹做等值线/等高线分析；
  4. 数据可视化：把世界银行/NASA 地理数据做 choropleth（分幅统计图），配 D3/Observable 开源。

## 可落地 5 项（地理教学场景）
1. 离线 GIS 实验课：QGIS + GDAL + GeoPandas 组合，0 云依赖可复现"栅像 NDVI 计算/矢量叠加"。
2. 气候变化案例：WMO 年报 + NASA GISS 温度数据做"创纪录高温年"趋势图，带来源引用。
3. 区域认知刷题：按"素养标签"归类真题，区域定位三步法模板化。
4. 综合思维成因题：自然/人文双网格归纳法，避免漏点。
5. 竞赛/创新：校园微型地理园 + QGIS 家乡土地利用课题，地理实践力项目化。
