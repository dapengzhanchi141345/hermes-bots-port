## 铁律（永不可犯）

### ⚡ 日柱双验证铁律
每次输出日柱前，必须同时用以下两种方法验证，结果一致方可输出：
- **主基准法**：2000年1月7日=甲子日
- **副基准法**：2024年1月1日=甲子日
- **已知点查证**：检查目标日期是否在已知可靠数据中

### ⚡ 文昌口诀法铁律
口诀（《渊海子平》，禁止用推导替代口诀）：
甲巳 乙午 丙戊申 丁己酉 庚亥 辛子 壬寅 癸卯

双查法（不可省略）：
1. 口诀法 → 背口诀定位（第一优先级）
2. 阴阳配法 → 阴干配阴支 / 阳干配阳支验证
3. 两法对照无误方可定论

### ⚡ 时柱复核铁律

### 升级后的工作流

1. **输入归一**：公历+出生地经纬度+时区 → IANA tzdb 还原当地标准时。
2. **真太阳时**：TST = 标准时 + 4×(λ−120°) + EoT(ΔT修正)；记录所用经度与修正量。
3. **节气定月柱**：用 Skyfield 计算太阳黄经到达各节气度数的 UTC 时刻，比对 PMO 发布值；以此判定月柱分界而非"初一"。

5. **时柱复核**：五鼠遁基于订正后日干；早/晚子时争议仍须向用户说明流派。
6. **降级标注**：农历/缺失分钟 → 标注精度级与误差窗口。

### 参考代码片段（Skyfield 求节气时刻）

```python
from skyfield.api import load, utc
from datetime import datetime
from skyfield.almanac import find_discrete
import numpy as np

def solar_longitude_at(ts, target_deg):
    """二分法求太阳视黄经=target_deg 的精确 UTC 时刻"""
    eph = load('de421.bsp')
    sun = eph['sun']
    earth = eph['earth']
    def f(t):
        astrom = earth.at(t).observe(sun)
        lon = astrom.ecliptic_latlon()[0].degrees % 360
        return lon - target_deg
    # 在目标月份附近二分（示例：立春 315°）
    lo, hi = ts.utc(2026, 2, 1), ts.utc(2026, 2, 10)
    for _ in range(40):
        mid = ts.tt_jd((lo.tt + hi.tt) / 2)
        if f(lo) * f(mid) <= 0:
            hi = mid
        else:
            lo = mid
    return hi.utc_iso()
```
