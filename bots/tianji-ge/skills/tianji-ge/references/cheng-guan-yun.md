### 1. 四柱八字排盘（排盘准确性第一要务，错一字满盘皆输）

**排盘核心规则（必须严格遵守）：**

- **年柱**：以**立春**为年柱分界，**不是**以正月初一（春节）为界。公历2月4日±1日交立春，立春前属前一年干支，立春后（含当日）属新年干支
- **月柱**：以**节气**为月柱分界，**不是**以农历初一为界。严格按节气划分：
  - 寅月（正月）：立春→惊蛰 / 卯月（二月）：惊蛰→清明 / 辰月（三月）：清明→立夏
  - 巳月（四月）：立夏→芒种 / 午月（五月）：芒种→小暑 / 未月（六月）：小暑→立秋
  - 申月（七月）：立秋→白露 / 酉月（八月）：白露→寒露 / 戌月（九月）：寒露→立冬
  - 亥月（十月）：立冬→大雪 / 子月（十一月）：大雪→小寒 / 丑月（十二月）：小寒→立春
- **日柱**：**必须查万年历**，不可自行推算。日干支是八字中最精密的环节，手工推算极易出错
- **时柱**：
  - 以真太阳时为基准（优先使用），若用户未提供经度，按北京时间减约15分钟/经度进行校正
  - ⚠️ **早子时 vs 晚子时争议**：23:00-00:00为晚子时/夜子时，00:00-01:00为早子时。主流做法有两种流派：
    - **不分派**：一日以23:00为始，23:00-01:00同属当日干支时日柱不变
    - **分派**：23:00-00:00属当日干支日柱不变，00:00-01:00属次日干支
    - **必须**向用户说明采用了哪种划分法，并说明结论可能因流派不同而有差异

**排盘完整要素**：年/月/日/时四柱天干地支 → 地支藏干 → 十神排列 → 纳音 → 空亡 → 神煞

**第一步：定贫富贵贱寿夭（大框架）**
1. 看五行是否缺一——所缺是否为财官（妻星、夫星）？缺的往往是缘分差的

**第二步：取用神定格局（核心判断）**

⑤ **切忌**：不可将建禄格的用神判定简化为普通身旺格的处理方式——"身旺喜火土"是对的，但忽略了"建禄格先制劫"这一格局派的核心法则

### 升级后的工作流

1. **校时**：经度时差 + 均时差 → 真太阳时 → 定时辰（历史生辰查 IANA tzdb）。
2. **定节气**：VSOP87 求太阳视黄经，定气法取交节瞬时时刻，定月柱与年柱分界。
3. **定日柱**：儒略日起算，日柱以子正（真太阳时 00:00）为界，不用北京时间 23:00 简化法。
4. **交叉验证**：第二套引擎（skyfield + DE440s）复算，四柱逐柱比对，任一项不一致即停机。
5. **排盘输出**：先给机器可读的四柱/大运/命盘数据，再做人文解读。
6. **解读**：结论分层作答（格局 / 大运 / 流年），每层给出可证伪的时间窗口。
