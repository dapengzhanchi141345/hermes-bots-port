# 玄学域 SOTA 增强技能（2026 版）

> 检索日 2026-09-27 · 带来源。**红线：本节为传统文化科普素材，不作决策依据，不构成医疗/投资/法律建议；涉及婚丧嫁娶/置业/投资请结合现实与专业意见。**

## 1. 八字（子平）SOTA 方法论
- **排盘**：四柱（年/月/日/时）由真太阳时推，需换算当地经度差（如 <PHONE> 坐标：东八区 + 当地经度 -120° 时差）。**时差公式**：真太阳时 = 钟表时 + (当地经度 - 120°) × 4 min + 均时差。
- **用神/格局**：2025-2026 学界争议仍在——"格局派"（子平格局）vs "旺衰派"（月令+地支藏干）vs "调候派"（气候平衡）三派并行，**教学/解读注明所用流派**，不混搭。
- **大运/流年**：大运以月柱起，阳男阴女顺排，阴男阳女逆排；流年看天干合冲 + 地支刑冲合害。
- **红线**：八字解读仅供文化参考，不作人生决策依据；涉及健康须就医，涉及投资须看基本面。

## 2. 紫微斗数 SOTA
- **排盘**：以农历生月+日时定命宫，十四主星（紫微/天机/太阳/武曲/天同/廉贞/天府/太阴/贪狼/巨门/天相/天梁/七杀/破军）入十二宫。
- **四化**：生年四化（禄/权/科/忌）看先天格局；大限四化看十年运；流年四化看当年事。**四化表以流派为准**（中州/钦天/三合各表略有差异）。
- **教学**：开源排盘工具（如 `ziwei` Python 库，https://github.com）做演示；解读注明流派 + 仅作文化参考。

## 3. 风水（堪舆）SOTA
- **流派**：形势派（峦头，看山形水势）vs 理气派（玄空/八宅/奇门，看方位坐向）；现代城市公寓多用「玄空飞星」简化版。
- **教学可用**：「八宅法」（东四宅/西四宅）最易入门；「玄空飞星」需罗盘坐向数据。**红线**：风水布置仅作文化/心理安慰，不作置业/投资依据；涉及房屋买卖看合同与实地。

## 4. 梅花易数 / 奇门遁甲 SOTA
- **梅花易数**：以起卦时辰 + 卦象数推事，适合教学演示"随机起卦"；开源排盘工具可直接用。
- **奇门遁甲**：九宫 + 九星 + 八门 + 三奇六仪，体系复杂；教学做「简版九宫方位」即可，**红线：不作投资/决策依据**。

## 5. 可落地 5 项（文化科普红线）
1. 任何解读首行必带「传统文化科普，不构成医疗/投资/法律建议，仅作文化参考」。
2. 排盘注明流派（子平格局/旺衰/调候；紫微中州/钦天；风水形势/理气）。
3. 真太阳时换算给公式，不硬套钟表时。
4. 涉及健康/投资/置业，末尾加「请结合现实与专业意见（就医/看基本面/看合同）」。
5. 开源排盘工具（ziwei/奇门 Python 库）做教学演示，不联网，可复现。
