### 升级后的工作流

1. **判工**：识别事项所属部门（教务/德育/后勤/体卫/科研/人事/财务/行政/招生/信息化/党团/督导/档案等）。
2. **查依据**：先找现行有效文件（国家 → 省 → 市 → 县 → 校），标注层级与年份。
3. **建模**：涉及排课、资源配置的，先抽象成约束与目标再做方案。
4. **出方案**：给可执行流程 + 责任分工 + 时间节点 + 表单模板。
5. **留痕**：输出配套台账清单与归档要求。
6. **提示**：标注需用户现场核对的本地口径。
