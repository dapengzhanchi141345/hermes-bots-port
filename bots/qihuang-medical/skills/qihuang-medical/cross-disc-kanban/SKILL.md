# 跨学科互通课题 · 调度工作流(岐黄医典 × 格物致知)

适用: 收到 @gewu-zhidao(格物致知·科研智库)发来的跨学科课题拆分清单(如「四维九式·中式体质测评」Phase 1 子题), 我团承接学术子题(A 组)、对方承接科研子题(B 组)的任务。依据: 名录 {{WORKBUDDY}}\内容中心\知识库\格物致知_学科互通名录_双向协作协议.md(平级对等、双署名、回收四件套)。

## 工作流(五步, 按序执行)
1. **判归属**: 只领中医学术侧子题(体质判定/功法处方/传变规则/体例/安全声明); 科研侧(申报框架/统计/信效度/混合方法/PRISMA/伦理)一律不碰, 留给对方。
2. **拆席位并行派子代理**: 每个子题 = 一个 delegate_task 子代理, 扮 1 个 persona(见席位表), 多子题并行发。context 必带: persona md 路径 + 理论母题(中医太极深度融合_理论内核.md) + 互通协议路径 + 已定稿的上游子题文件路径(下游子题要引用上游)。
3. **验收**: 落盘到 {{WORKBUDDY}}\内容中心\交付\四维九式_A组\(或课题名对应目录), 逐篇 grep 校验: 四件套「核心结论」≥1、免责「不构成医疗建议」≥1、行数在上限内、双署名(学科团 + 格物致知回收四件套)。
4. **回传**: message_agent 分 2-3 条短消息(≤8K 字符/条), 内容 = 路径+行数 / 席位名单 / 遗留问题核销清单(按 A1-A5 分组, 标明哪些移交 B 组)。绝不发整包长消息。
5. **遗留归并**: 各子题遗留项统一按「移交 B 组(对方)」或「本团内部再派」分类, 在回传消息里写清归属, 避免对方空转。

## 陷阱(每条 = 本次踩过的坑)
- **子代理总结 ≠ 落盘**: 子代理可能停在推理阶段、只回传总结没调 write_file, 文件实际不存在。每个子代理 context 里必须写「先 write_file 落盘再总结」, 回收后 ls 目录验证, 缺哪个补派哪个(单独重派, 不要整批重来)。
- **经典原文出处必须联网核**: 「见肝之病知肝传脾」出自《金匮要略·脏腑先后病》而非《素问·玉机真藏论》(常见误植); 子代理凭记忆引经据典一律标「待核」降级置信度, 主理人验收时抽查 1-2 条出处, 查不到官方来源就按「待核」放行并记入遗留, 不阻塞交付。
- **message_agent 单条 >8K 字符会流超时**: 回传内容拆 2-3 条短消息, 每条以「【补发/续】」或子题编号开头, 防止被截断后重发整包。
- **delegate_task 任务描述过大也会流超时**: 多子题并行时每条 task 的 goal+context 控制在合理篇幅, 超长母题路径只给路径不给全文, 让子代理自己去 read_file。
- **双栏红线随内容走**: 文化阐释层(气/经络/阴阳/五行/五禽配脏/治未病口号)与证据层(国标判定线/团标背书/HRV/姿态等可测变量)分列, 机制句写「假设为/读出头/可操作化为」, 不写因果断言; 成品文末必带「中医文化科普, 不构成医疗建议」。
- **判定表述用「偏颇倾向」**: 不得写「诊断为×质」; 偏颇质得分>40 为干预阈值(GB/T 46939—2025, 2026-04-01 实施), 30-39 为「倾向」, 平和质≥60 且余质<40(2009 量表判读规则沿用)。
- **青少年适配项留白待 B 组**: 心率区间/教学卡/急救操作卡不在 A 组拍板, 矩阵里留白 + 标注归属 B2/B4/B6, 避免越界代笔科研结论。
- **涉政策(政策落点/课标衔接)标注「以当地最新官方文件为准」**; 涉 AI 评分保持「AI 初评 → 人工终判」, 信效度<0.7 停用自动给分(与对方 B3 口径一致)。

## 验收命令(每次交付前跑一遍)
```
cd "{{WORKBUDDY}}/内容中心/交付/<课题名>_A组" && wc -l *.md && for f in *.md; do echo "== $f =="; grep -c "核心结论" "$f"; grep -c "不构成医疗建议" "$f"; done
```
每篇「核心结论」≥1、「不构成医疗建议」≥1, 缺则补派。
